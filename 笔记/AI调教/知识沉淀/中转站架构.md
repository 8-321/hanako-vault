## 一、三位一体调度架构

根据高端中转站运维经验，系统已完成资源的分层物理隔离，实现了"一键最强、一键最省"。

### 资源分层

| 资源类别 | 包含供应商 | 调度优先级 | 计费倍率 | 核心目的 |
|:---|:---|:---:|:---:|:---|
| **Subscription（套餐组）** | MiniMax TokenPlan, Kimi 190+ | **1000 (极高)** | **0.0x** | **无限白嫖**：已付过费，必须优先跑 |
| **Relay（中转组）** | 77Code, CodeFlow, SquareFace | **500 (主力)** | **0.1x** | **主力输出**：一折计费，中转平权，不分高下 |
| **Official（官方组）** | DeepSeek 官方直连 | **100 (保底)** | **1.0x** | **战略储备**：仅在极端复杂或拥塞时动用 |

## 三、使用方式

### 基础配置

```
Base URL: http://你的VPS_IP:3000/v1
API Key:  你在 One-API 里生成的令牌
```

### 倍率说明

- 调用套餐内模型（如 `MiniMax-M2.7`）：不扣点数
- 调用中转模型（如 `claude-opus-4-6`）：按 1/10 价格计费

## 四、部署规范（One-API）

### Docker 一键部署

```bash
# 在 VPS 上运行（Ubuntu/Debian）
docker run --name one-api -d \
  --restart always \
  -p 3000:3000 \
  -e TZ=Asia/Shanghai \
  -v /home/ubuntu/data/one-api:/data \
  justsong/one-api
```

### 初始配置

- 登录地址：`http://你的VPS_IP:3000`
- 初始账号：`root`
- 初始密码：`123456`
- **警告**：使用 root 用户初次登录后，务必修改默认密码

### 迁移备份

```bash
# 备份
tar -czf one-api-backup.tar.gz /home/ubuntu/data/one-api

# 迁移到新机器
scp one-api-backup.tar.gz new-server:/home/ubuntu/
tar -xzf one-api-backup.tar.gz
# 重新运行，/data 挂载路径相同即可
```

## 五、Nginx 反向代理配置

```nginx
server{
   server_name openai.your-domain.com;

   location / {
          client_max_body_size  64m;
          proxy_http_version 1.1;
          proxy_pass http://localhost:3000;
          proxy_set_header Host $host;
          proxy_set_header X-Forwarded-For $remote_addr;
          proxy_cache_bypass $http_upgrade;
          proxy_set_header Accept-Encoding gzip;
          proxy_read_timeout 300s;
   }
}
```
