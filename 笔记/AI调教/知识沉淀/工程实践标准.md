# 工程实践标准

> **用途**：所有代码交付必须遵循的工程标准
> **适用范围**：Python 后端、前端、配置脚本、CI/CD

---

## 一、Python 后端标准

### 生产级 Python 要求

1. **强制类型注解**（mypy 严格模式）
2. **异步/await 全链路使用**（FastAPI + httpx + aioredis）
3. **上下文管理器**管理资源
4. **pydantic v2** 模型验证
5. **dataclasses** 优化 DTO
6. **自定义元类**实现模式注册
7. **__slots__** 优化内存
8. 符合 PEP484/PEP585/PEP604 类型规范

### 分层架构

```
app/
  routes/   （APIRouter 模块化路由）
  services/ （领域服务）
  models/   （SQLAlchemy 2.0 声明式模型）
  schemas/  （pydantic 响应/请求模型）
  core/     （配置/中间件/安全）
  tasks/    （Celery 任务）
tests/
  （pytest 分层测试）
```

- 依赖注入：FastAPI Depends 系统
- 查询优化：SQLAlchemy 2.0 select() + 预加载策略
- 缓存抽象：Redis + L1/L2 缓存装饰器

### Python 工具链

| 工具 | 用途 |
|:---|:---|
| flake8 + black + isort + pre-commit | 代码质量 |
| mkdocs-material + pdoc | 文档生成 |
| poetry + pyproject.toml | 依赖管理 |
| mypy + strict 配置 | 类型检查 |
| bandit + safety | 安全扫描 |
| pytest | 测试 |

### 高性能优化

- 异步 ORM：SQLAlchemy 2.0 async_session
- JIT 加速：numba 关键路径优化
- 连接池：asyncpg + aiomysql 驱动
- 序列化优化：orjson 替换 json

### 安全措施

- 依赖漏洞扫描：pip-audit
- 敏感字段加密：cryptography.fernet
- 输入净化：bleach + sanitization 中间件
- 日志脱敏：自定义 logging.Filter

## 二、前端标准

### 核心原则

- 响应式设计，移动端优先
- 语义化 HTML
- CSS 变量管理主题
- 模块化 JavaScript（ES6+）

### 代码规范

- ESLint + Prettier
- 组件化开发
- 状态管理清晰（Pinia/Zustand）
- 错误边界处理

## 三、质量控制

### 代码审查清单

| 检查项 | 标准 |
|:---|:---|
| 可运行性 | 直接执行无报错 |
| 功能完整性 | 需求全部覆盖 |
| 类型安全 | mypy 无错误 |
| 代码风格 | black 无警告 |
| 测试覆盖 | 核心路径有测试 |
| 安全扫描 | bandit 无高危 |

### 性能基准

- API 响应时间 < 200ms（p95）
- 页面加载时间 < 3s
- 无内存泄漏

## 四、部署规范

### Python 部署

```bash
# Gunicorn + Uvicorn 配置
gunicorn app.main:app \
  -w 4 \
  -k uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:8000 \
  --timeout 300 \
  --log-level info
```

### Docker 规范

- 多阶段构建
- 非 root 用户运行
- 最小化镜像大小
- 健康检查配置

## 五、文档要求

每个项目必须包含：

1. **README.md**：项目概述、快速开始、API 文档
2. **pyproject.toml** 或 **package.json**：依赖管理
3. **.env.example**：环境变量模板（无真实密钥）
4. **CONTRIBUTING.md**：贡献指南

---

## 六、禁止事项

- 不写 "TODO" 而不写实际实现
- 不跳过单元测试的编写
- 不使用硬编码的魔法数字
- 不在生产代码中留 debugger
- 不泄露任何 API Key 或密钥
