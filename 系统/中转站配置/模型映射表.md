## 二、调度策略

### 自动调度规则

```
请求到达 → 检查 Subscription 组 → 有可用模型 → 优先使用
                              ↓ 无可用
            检查 Relay 组 → 有可用模型 → 0.1x 计费
                              ↓ 无可用
            检查 Official 组 → 使用官方渠道
```

### 手动切换

如需强制使用特定渠道，可在 API Key 前添加渠道前缀：
```
sk-use-special-channel:你的API密钥
```

## 五、故障排查

| 问题 | 可能原因 | 解决方案 |
|:---|:---|:---|
| 401 Error | API Key 失效 | 检查渠道配置，删除失效渠道 |
| 超时 | 渠道负载高 | 切换到备用渠道 |
| 模型不可见 | 未同步 abilities 表 | 强制同步数据库 |
| 额度不足 | 渠道耗尽 | 检查渠道余额，切换备用 |
