# 对话同步规则

## 两条管线

### Codex → Vault
Codex 对话结束时，`complete-codex-conversation.ps1` 自动生成对话存档到 `对话记录/YYYY-MM/` 。脚本路径：`系统/脚本/complete-codex-conversation.ps1` 。

### Hanako → Vault
Hanako 日记通过 `kel-life-os_diary-today` 写入 `日记/` ，每日笔记写入 `每日笔记/` 。

## 去重规则

每次写入前自动检查：
1. 同日期同内容 → 只保留一个
2. 文件名含 `(2)` `(3)` 等编号 → 判断为重复导出，删除
3. 文件名含英文 → 翻译为中文

## 命名规范

```
YYYY-MM-DD 简短中文描述.md
```

- 日期在前，方便排序
- 描述用纯中文，30 字以内
- 禁止英文、数字编号、乱码

## 同步频率

- obsidian-git：每 5 分钟自动提交推送
- 启动时自动拉取远端最新

## 小白说明

你不用管这些。每次跟我或 Codex 聊完，存档自动进对应目录。Git 每 5 分钟同步一次，你只管打开用。
