1. 【铁律】自己立的规定要第一个遵守。今天创建了 diary-scribe 规范，规定"同日多轮对话应追加而非新建文件"，然后立刻违反——先创建了独立的第二篇日记文件，之后才合并删除。kel对此不满："这个日记写入失败在之前已经犯过错误了，还犯错误"。规范不是给别人看的，是自己执行的。
2. 在 bash here-doc 里生成 Python 处理 Windows 路径时，不要手写反斜杠字符串转义；优先用 pathlib.as_posix()、chr(92) 或原始字符串变量，写完先用 sed/read 核对脚本。
3. 在 bash here-doc 生成 Python 处理 Windows 路径时，避免写裸反斜杠字面量，优先用 pathlib 或 chr(92)，否则容易触发 unterminated string literal。
4. 在 bash here-doc 生成 Python 脚本时，路径分隔转换优先用 pathlib.Path(...).as_posix() 或 chr(92)，不要手写易被转义吞掉的反斜杠字面量。
