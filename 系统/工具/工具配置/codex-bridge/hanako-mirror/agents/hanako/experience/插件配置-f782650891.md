1. 【类别】插件配置
【触发条件】HyperFrames 插件 diagnostics 报错 `spawn npx ENOENT`
【铁律】不要假设 Hanako server 继承了终端 PATH；在插件配置里把 `hyperframesCommand` 写成绝对可执行链（如 `E:/node/node.exe E:/node/node_modules/npm/bin/npx-cli.js --yes hyperframes`）以避免 PATH 缺失。
【反面案例】默认 `npx --yes hyperframes` 与 `E:/node/npx` 在 server 进程里都可能 ENOENT
【检查方式】调用 `/api/plugins/hanako-hyperframes/api/diagnostics`，看到 `ok:true` 且版本号（如 0.5.7）才算配置完成
