# 微信群链接总结Agent

## 是什么
让个人 Agent 监听指定微信群链接，自动总结并沉淀到 Obsidian 的低摩擦入口。

## 核心内容
- 普通个人微信没有稳定官方监听群消息 API，第一版可走桌面微信 + wxauto 监听指定群 + 链接总结 + 自动回复。
- 保守规则：只监听白名单群，只处理 kel 自己发的链接，支持触发词如“总结 https://...”。
- 输出格式固定为标题、一句话结论、3-5 个要点、标签、原链接，并保存到 Obsidian `KelRecordAgent/Links/`。
- 核心总结能力要独立，微信只是入口；以后可换 Telegram、飞书、浏览器或剪贴板入口。

## 注意
wxautox Plus 可能需要设备授权；开源 wxauto 可能不适配新版 `Weixin.exe` 的窗口类。不要碰红包、支付、联系人管理和批量发消息。
