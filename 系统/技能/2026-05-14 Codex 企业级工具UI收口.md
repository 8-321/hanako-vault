# 企业级工具UI收口

## 是什么
把功能堆叠的 AI 工具界面收敛成高级、简洁、可长期使用的企业级主路径。

## 核心内容
- 首页只保留单主路径，用户进入后立刻知道下一步，例如“开始记录”或“开始整理”。
- AI 能力应在后台默默跑，设置、格式切换、调试项放进二级抽屉或设置页，不压迫主界面。
- 视觉用深色克制底板、细边框、低饱和点缀、清楚层级和短促动效，避免花哨演示感。
- 工程上先修数据流和字符串完整性，再换外壳，避免 UI 很新、底层逻辑还是旧的半成品。

## 注意
“顶级 UI”不是多加按钮和特效，而是降低心理负担。哲学负责主线克制，心理学负责低操作负担，社会学负责重复使用场景。
