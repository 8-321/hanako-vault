# 自媒体知识库与头像生成配置

## 是什么
用于把自媒体运营知识整理成 Obsidian 知识库，并为个人品牌头像生成准备可复用的视觉 prompt 与图片 provider 配置思路。

## 核心内容
- 自媒体知识库按模块组织：平台生态、内容选题、内容结构、运营指标、变现路径、个人IP、避坑指南。
- 个人IP定位围绕“人群 + 场景 + 价值主张”，小柯的成长实验室可突出成长、实验、大学生、AI工具、温暖探索感。
- 头像 prompt 要明确身份气质、品牌元素、构图、色彩、风格和限制，例如圆形头像、现代扁平插画、青绿色主色、珊瑚色点缀、无文字。
- Hanako 图片生成需同时满足模型注册、provider API Key、adapter 支持图片端点三件事；只有聊天模型 Key 不等于能生图。

## 注意
涉及概念调研时要联网核验；网络不可用时要说明来源边界。OpenAI 兼容中转站如果不支持 `/v1/images/generations`，即使有 `gpt-image` 模型名也会失败；火山引擎/Seedream 或官方 OpenAI Key 才是更稳路径。
