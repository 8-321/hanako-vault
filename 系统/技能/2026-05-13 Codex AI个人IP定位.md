# AI个人IP定位

## 是什么
把 kel 的 AI 方向从泛泛工具分享收束成有个人气质和长期叙事的 IP 原型。

## 核心内容
- 不做“AI 工具搬运号”，核心叙事是普通但野心很大的人如何用 AI 重建学习、表达、项目和生活系统。
- IP 原型可落在“生活实验者 / AI 自我实验室 / 荒原寻路者”，强调真实经验、行动记录和自我重构。
- 内容要从个人问题出发：混乱、记忆负担、学习低效、表达不准、项目难落地，再翻译成别人可用的方法。
- 视觉和文风要克制、真实、有笔记感，避免机构号、营销号和过满 AI 海报。

## 注意
个人 IP 不能只做宏大身份命名，必须持续产出可验证案例。市场先看“帮我省什么、解决什么”，再理解你的宇宙观。
