# 个人智能体五层架构

## 是什么
为 kel 的个人 Agent 设计一套可扩展的“脑子、记忆、工具、界面、护栏”分层架构。

## 核心内容
- 不从炫酷 autonomous agent 开始，先拆成核心编排、记忆层、工具层、界面层和安全护栏。
- 核心编排可选 LangGraph；OpenAI-first 可看 openai-agents-python；轻量结构化工具调用可用 Pydantic AI。
- 记忆层可参考 Letta，工具执行可接 browser-use、OpenHands、MCP、文件、Obsidian、n8n。
- 控制台可用 Dify、Open WebUI、n8n 或自研本地 Web Studio，避免把系统绑死在单一框架。

## 注意
个人智能体要先有可控流程和边界，再谈全自动。记忆、工具和界面解耦，后面换入口或换模型才不会重写全部。
