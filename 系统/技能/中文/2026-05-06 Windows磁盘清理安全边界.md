# Windows磁盘清理安全边界

## 是什么
用于清理 Windows C 盘前先判断哪些内容能删、哪些必须确认，避免把用户数据误当缓存删除。

## 核心内容
- 清理顺序先诊断再行动：查看磁盘剩余、顶级目录占用、AppData 大户、回收站和系统缓存。
- 优先清理可重建缓存：TEMP、Windows Update 缓存、浏览器缓存、npm/pip/yarn 缓存、缩略图缓存、官方 DISM 组件清理。
- 遇到 Tencent、Docker、Adobe、Code、JianyingPro、Programs、网盘目录时必须降级为“待确认”，因为里面可能混有聊天文件、容器数据、工程配置或便携软件。
- 删除前尽量输出清单，删除后立即检查回收站、应用状态和磁盘变化，出现异常先恢复再继续。

## 注意
不要把 AppData 下的“大文件夹”天然等同于缓存；微信/QQ、Docker、VS Code、Adobe、网盘和 Programs 类目录都可能藏真实用户资产。重复文件和整盘整理必须先只读扫描、按大小和哈希核验、让用户确认后再删。
