# 语音想法APK路线

## 是什么
把“脑电波记录想法”的不可行愿望，转译成可落地的语音想法收件箱 APK。

## 核心内容
- 第一版核心是一个大按钮：开始记录，录完转写/手动输入，再整理成今日想法、可写选题、项目线索、人生主线信号、公众号初稿。
- 技术路线可选 Capacitor + Android 工程快速交付 APK；若做长期原生能力，Android Kotlin/Java 最稳。
- 语音转文字三条路：系统 SpeechRecognizer 最快，上传转写更准但需联网和 API key，本地 Whisper 隐私好但重。
- 验收必须包括真机安装、麦克风权限说明、离线保存、Markdown 复制/分享、本地历史、中断恢复样例。

## 注意
第一版不做后台偷录、唤醒词监听、自动发布公众号、账号体系和复杂知识库。默认本地保存，联网整理必须明确提示。
