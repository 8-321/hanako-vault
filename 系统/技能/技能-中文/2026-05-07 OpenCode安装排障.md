# OpenCode安装排障

## 是什么
用于在 Windows 上安装 OpenCode，并在官网打不开、浏览器受限或下载超时时切换可行路径。

## 核心内容
- 先确认用户说的 OpenCode 具体指向，避免同名项目误装；优先查官网、GitHub release、npm、winget、VS Code 扩展。
- Windows 桌面版可用官方稳定版安装包，下载完成后核对文件大小和扩展名，再让用户双击安装。
- 如果浏览器打不开官网，尝试命令行下载到工作目录，并把安装包路径交付给用户。
- 下载大文件超时时不要死磕，换镜像、换网络、给出手动链接或分段下载方案。

## 注意
不要在来源不明的网站下载安装包。安装包能下载不等于已安装完成，最终还要验证程序是否能启动、是否已加入 PATH 或桌面快捷方式。
