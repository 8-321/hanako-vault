# 灵感库需求库发动机

## 是什么
把灵感库从“收集想法的仓库”升级为能不断产出选题、项目和内容的发动机。

## 核心内容
- 顶级灵感库不是堆素材，而是把真实经历压缩成洞察、选题、作品和个人品牌资产。
- 需求库要记录“谁在什么场景下因为什么痛而需要什么”，可结合 Jobs To Be Done、设计思维和 creator content system。
- 主路径：随手捕捉 → 归类到灵感/需求 → 提炼母题 → 生成内容/项目假设 → 复盘反馈。
- HTML 主页应小白友好、整洁美观，入口少、层级清楚，像个人工作台，不像机构后台。

## 注意
不要把灵感库做成收藏夹。每条灵感都要能回答：它解决谁的什么问题，能变成哪篇内容、哪个服务或哪个小项目。
