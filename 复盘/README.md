# HeartBeat 巡检

这里只做一件事：记录不同助手的心跳巡检。

## 看哪里

| 助手 | 日志 |
|---|---|
| 主助手 含 | `含/patrol-log.md` |
| 含章 | `含章/patrol-log.md` |
| 含舟 | `含舟/patrol-log.md` |
| 含野 | `含野/patrol-log.md` |

## 写法

每次只写五行：

```md
## YYYY-MM-DD HH:mm 巡检

- 结论：有没有问题。
- 变动：看到什么变化。
- 行动：做了什么。
- 风险：有没有不能乱动的东西。
- 下一步：是否需要 kel 确认。
```

不要再堆研究笔记。需要长期保存的，先写进日记或以后再单独决定。
