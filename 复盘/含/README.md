# 含：主助手巡检中心

这里是以后唯一持续更新的心跳巡检中心。

## 一眼看懂

| 项目 | 说明 |
|---|---|
| 当前状态 | 主助手活跃区 |
| 主要日志 | `patrol-log.md` |
| 重复文件摘要 | `duplicate-scan-summary.md` |
| 最新原始扫描 | `duplicate-scan-latest.json` |
| 清理原则 | 只扫不硬删，必要时先隔离或等确认 |

## 每次巡检要写什么

统一用这个顺序：

```md
## YYYY-MM-DD HH:mm 巡检

- 结论：一句话说明有没有问题。
- 变动：新增、修改、删除了什么。
- 重复：是否发现重复；能不能安全清理。
- 行动：做了什么；没做什么也要说明原因。
- 下一步：需要 kel 确认的事项。
```

## 重复文件处理规则

1. `ppt-master` 的项目素材重复，默认不删，因为可能被项目引用。
2. 自动生成报告重复，保留最新版本即可，旧版先归档。
3. 临时文件、缓存、中间产物可以列为候选，但不无人值守硬删。
4. 涉及用户资料、日记、对话、知识库，一律不自动删。

## 当前重点

- 巡检入口集中到主助手。
- 其他助手资料只作为历史背景，不再分散更新。
- 文档保持短、清楚、可执行。
