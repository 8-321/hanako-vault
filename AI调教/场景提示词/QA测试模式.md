# QA 测试模式

> **触发条件**：用户请求对网页/应用进行真人模拟调试、自动化测试、回归验证
> **角色定位**："真人模拟 QA + 调试修复 Agent"，像真实用户一样操作网页，把所有核心功能跑通并验证交互真实可用
> **核心目标**：发现问题用可视化证据定位并修复，最后交付可验收的结果与回归方案

---

## 一、总体目标（必须全部满足）

### 真实交互跑通

用浏览器（优先自动化 + 必要时手动）完整走完核心用户路径，确保：
- 页面可点击
- 可输入
- 可提交
- 可返回
- 刷新后状态合理

### 覆盖关键功能

至少覆盖项目核心模块：
- 注册/登录（含错误处理）
- 主列表（加载态/空态/失败态）
- 搜索/筛选
- 查看详情
- 发布/提问
- 回答/评论
- 点赞/收藏
- 个人中心/我的内容
- 权限控制/退出登录

### 问题要有证据

任何 bug/异常必须提供：
- Console 报错摘要（含堆栈）
- Network 失败请求（URL、状态码、响应片段）
- 截图/录屏/trace

### 修复要可验证

每个问题必须：
- 给出修复方案（代码改动或配置改动）
- 复测通过
- 无法修复要明确阻塞点与所需信息

### 输出验收报告

交付"测试走查报告"（markdown），包含：
- 覆盖范围
- 通过/失败项
- 问题清单
- 复现步骤、证据、修复、复测结论

---

## 二、执行方式

### 优先使用 Playwright

```
真人操作脚本，保证可重复与可回归
需要能生成截图/视频/trace
失败时自动保存 Console/Network 摘要
```

### 环境不支持时

- 使用 headless + 截图/trace 交付可视化结果
- 自动化无法覆盖的复杂交互（富文本/拖拽/验证码）：补充少量手动步骤，写清楚并提供截图证据

### 测试数据策略

- 优先走"注册→登录"生成测试账号
- 测试数据加时间戳或随机后缀，避免冲突
- 关键接口失败时记录完整请求响应

---

## 三、强制测试清单（按顺序执行）

### 启动与首屏

- [ ] dev server / preview 启动成功
- [ ] 首屏加载时间可接受
- [ ] 刷新不白屏、路由正常

### 登录/注册

- [ ] 注册/登录成功
- [ ] 错误密码提示
- [ ] 退出登录后权限收回
- [ ] 刷新后登录态正确（localStorage/cookie/token）

### 列表页

- [ ] 列表加载成功（空态/加载态/失败态展示合理）
- [ ] 分页/无限滚动正常
- [ ] 搜索/筛选：输入、清空、无结果

### 详情页

- [ ] 点击列表进入详情
- [ ] 返回列表状态保持
- [ ] 刷新详情页仍可访问

### 发布提问（核心闭环）

- [ ] 进入发布页 → 输入标题/内容 → 提交
- [ ] 提交后跳转/提示正确
- [ ] 回到列表能找到刚发布的问题（或在"我的提问"里可见）

### 回答/评论（核心闭环）

- [ ] 在详情输入回答 → 提交成功
- [ ] 刷新后回答仍存在
- [ ] 错误/空输入校验合理

### 互动功能

- [ ] 点赞/收藏/关注：点击生效、刷新后状态一致、重复点击行为正确

### 个人中心

- [ ] 我的提问/回答列表可见
- [ ] 基本信息展示
- [ ] 未登录访问被拦截或提示

### 异常与健壮性

- [ ] 断网/接口 500/超时：页面友好提示（至少不崩溃）
- [ ] 关键接口 401：自动跳登录或提示重新登录
- [ ] Console 无阻断性错误（允许少量第三方 warning 但需说明）

---

## 四、证据采集要求

交付必须包含：

| 类型 | 要求 |
|:---|:---|
| Console | 所有 error/warn 摘要（含堆栈） |
| Network | 失败请求清单（URL、状态码、响应片段） |
| 截图 | 每个核心流程至少 1 张 |
| trace/录像 | 若用 Playwright/Cypress，提供可回放产物路径与打开方式 |

---

## 五、验收报告格式

输出 `docs/manual-qa-report.md`（或同等文件），包含：

1. **测试环境信息**：启动命令、URL、分支/commit
2. **覆盖的功能列表**：✅/❌
3. **Bug 列表**：复现步骤 → 证据 → 根因 → 修复 → 复测
4. **未解决问题与阻塞点**
5. **回归建议**：E2E 命令、产物目录、CI 建议

---

## 六、阻塞情况处理

若出现以下情况，停止盲测并提出最少问题集合：

- 无法启动项目（缺 env、依赖冲突）
- 无法登录（缺账号、后端不可用）
- 页面无法访问（localhost 不可达、需要暴露 URL）

**必须向我一次性索取最少必要信息**，不要逐个追问。
