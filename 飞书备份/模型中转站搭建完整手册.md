## 一、什么是模型中转站

模型中转站（API Relay）是一种**聚合和转发 AI 模型 API 请求**的服务。

```
你的用户  ──→  你的中转站  ──→  OpenAI / Claude / Gemini / DeepSeek 等官方 API
              （你控制）         （你的上游渠道）
```

用户只需要访问你提供的地址和 Key，即可使用各大顶级 AI 模型，**你赚中间的差价或服务费**。

## 二、准备工作清单

### 2.1 境外服务器（VPS）

> **为什么必须是境外？** OpenAI、Claude 等国外模型会封锁中国大陆 IP，如果服务器在国内就无法调用。

**推荐购买平台**：

| 平台 | 地区 | 价格 | 推荐理由 |
|:---|:---|---:|:---|
| 腾讯云轻量 Lighthouse | 香港、新加坡 | ¥60-80/月 | 界面中文，小白首选 |
| 阿里云 ECS | 香港、美西 | ¥80-120/月 | 稳定，支持宝塔 |
| Vultr | 日本、美国 | $6/月起 | 性价比高，按小时计费 |
| Hetzner | 德国、美国 | €4/月起 | 超便宜，高配低价 |

**最低配置**：
- CPU：1核 或 2核
- 内存：**2GB RAM（低于 1GB 跑不动 MySQL）**
- 硬盘：20GB SSD
- 带宽：3Mbps 以上
- 系统：**Ubuntu 22.04 LTS**

### 2.2 域名

- **推荐**：Cloudflare Registrar（最便宜）
- 买完域名后把 DNS 管理切换到 **Cloudflare**（免费 CDN）

### 2.3 上游 API Key

至少需要一个大模型平台的 Key（见下方渠道资源手册）。

## 三、从零部署 New API（Docker）

### Step 1：更新系统包
```bash
apt update && apt upgrade -y
```

### Step 2：安装 Docker
```bash
curl -fsSL https://get.docker.com | bash -s docker
docker --version  # 验证
```

### Step 3：安装 Docker Compose
```bash
apt install docker-compose-plugin -y
docker compose version
```

### Step 4：创建工作目录
```bash
mkdir -p /opt/new-api && cd /opt/new-api
```

### Step 5：创建配置文件
```bash
nano docker-compose.yml
```

粘贴以下内容（把 `your_secret_key_change_this_123456` 改成随机字符）：
```yaml
version: '3'
services:
  new-api:
    image: calciumion/new-api:latest
    container_name: new-api
    restart: always
    command: --log-dir /app/logs
    ports:
      - "3000:3000"
    volumes:
      - ./data:/data
      - ./logs:/app/logs
    environment:
      - SQL_DSN=
      - SESSION_SECRET=your_secret_key_change_this_123456
      - TZ=Asia/Shanghai
      - GEMINI_SAFETY_SETTING=BLOCK_NONE
    healthcheck:
      test: ["CMD-SHELL", "wget -q -O - http://localhost:3000/api/status | grep -o '\"success\":\\s*true' | head -1 || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 3
```

### Step 6：启动
```bash
docker compose up -d
# 等待1-2分钟
```

### Step 7：验证
```bash
docker ps
# 看到 new-api 容器状态是 Up 就成功

# 浏览器打开：http://服务器IP:3000
# 默认账号：root  密码：123456
# ⚠️ 登录后立即修改密码！
```

## 四、配置域名和 HTTPS（Nginx Proxy Manager）

### Step 1：部署 Nginx Proxy Manager
```bash
mkdir -p /opt/npm && cd /opt/npm
nano docker-compose.yml
```

粘贴：
```yaml
version: '3'
services:
  npm:
    image: jc21/nginx-proxy-manager:latest
    container_name: nginx-proxy-manager
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
      - "81:81"
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
```

启动：
```bash
docker compose up -d
# 访问：http://服务器IP:81
# 默认账号：admin@example.com  密码：changeme
```

### Step 2：DNS 解析
在 Cloudflare 添加 A 记录：
- Name：`api`
- Value：你的服务器 IP
- 云朵图标：**灰色（仅 DNS，不代理）**

### Step 3：在 NPM 添加反向代理
1. `Proxy Hosts` → `Add Proxy Host`
2. Domain Names：`api.yourdomain.com`
3. Scheme：`http`，Forward Hostname：`127.0.0.1`，Forward Port：`3000`
4. SSL 标签：选 `Request a new SSL Certificate`，勾 `Force SSL`，填邮箱，Save

## 五、后台配置

### 5.1 添加渠道（上游 API）

1. 左侧菜单 → **渠道** → **添加渠道**
2. 填写：
   - **类型**：选你的上游（OpenAI/DeepSeek/Gemini 等）
   - **名称**：自己认识就好
   - **密钥**：粘贴你的 API Key
   - **模型**：点击「填入支持的模型」自动填充
3. 点「测试」→ 绿色成功 → 保存

> 可添加多个渠道，New API 会自动负载均衡和故障转移。

### 5.2 创建令牌（分发给用户的 Key）

1. 左侧菜单 → **令牌** → **添加令牌**
2. 配置：名称、额度、有效期、IP 限制
3. 复制生成的 `sk-xxxxxxxx` 格式 Key 分发给用户

### 5.3 系统设置

| 设置项 | 推荐配置 |
|:---|:---|
| 注册需要验证码 | 开启 |
| 注册功能 | 按需开启/关闭 |
| 新用户初始额度 | 100～500 |
| 请求频率限制 | 60次/分钟 |

## 七、运营变现指南

### 商业模式

**模式1：卖 Key（最简单）**
- 用户买了 Key，在自己的工具（Cherry Studio/Cursor/NextChat）里配置使用
- 定价参考：
  - 体验包 100万 tokens → ¥5（成本约¥0.4，利润 ~1000%）
  - 标准包 1000万 tokens → ¥30（成本约¥4，利润 ~650%）
  - 专业包 5000万 tokens → ¥100（成本约¥20，利润 ~400%）

**模式2：订阅制（稳定收入）**
- 月度基础 ¥29/月 → 500万 tokens
- 月度标准 ¥59/月 → 2000万 tokens
- 月度旗舰 ¥99/月 → 5000万 tokens，含 GPT-4o/Claude

**模式3：开站+引流**
- 卖资料包 ¥39-99/份（可商用）
- 买了资料包的人成为你的第一批用户

### 引流渠道

1. **知识类社区**：知乎、CSDN、写教程文章，末尾附站点
2. **社群/私域**：QQ群/微信群，提供免费体验 Key 作为进群福利
3. **B站/抖音**：录"教你免费用 AI"视频，评论区引流
4. **程序员聚集地**：V2EX、Linux DO、GitHub README

### 安全设置（必做！）

- 关闭公开注册，用邀请码制度
- IP 频率限制：同一 IP 每分钟最多 30 次请求
- 每个 Key 设置额度上限和有效期
- 定期查看数据看板，发现异常立即封号
- 设置用量告警（超过 80% 额度时发邮件通知）

## 八、常见报错 FAQ

| 问题 | 原因 | 解决方法 |
|:---|:---|:---|
| `docker: command not found` | Docker 未安装 | `curl -fsSL https://get.docker.com | bash -s docker` |
| `Port 3000 is already allocated` | 端口占用 | `lsof -i :3000` 查看进程，kill 或改端口 |
| 容器一直 Restart | 内存不足/SESSION_SECRET 为空 | `docker logs new-api --tail 50` 查看日志 |
| 浏览器打不开 IP:3000 | 防火墙未开放端口 | 云服务商控制台开放 3000/80/443/81 端口 |
| 渠道测试 401 | API Key 填错/已过期 | 检查 Key 是否完整，检查 Base URL 末尾有无 `/v1` |
| 渠道测试 403 | 服务器 IP 被封 | 换服务器地区，或使用第三方批发渠道 |
| SSL 证书申请失败 | DNS 未生效/80端口未开 | 等 5-30 分钟 DNS 生效，开放 80 端口 |
