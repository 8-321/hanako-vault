# HanakoVault 使用案例

## 什么时候用这个库

- 调教 Hanako
- 整理 AI Agent 规范
- 保存对话记录和巡检记录
- 沉淀提示词、工作流和工具配置

## 案例 1：一次重要对话

1. 原始内容进入 `对话记录`
2. 可复用经验进入 `AI调教` 或 `工作流`
3. 踩坑进入 `技术资料库`
4. 需要长期遵守的规则进入 `99 - Agent指南与规范`

## 案例 2：新增一个 Agent 规则

1. 先放入 `收件箱`
2. 观察是否会重复使用
3. 确认有价值后，沉淀到 `99 - Agent指南与规范`

## 案例 3：发现一个工具配置方法

1. 记录到 `工具配置`
2. 如果是流程，补到 `工作流`
3. 如果是知识点，沉淀到 `技术资料库`
