### 阶段二：域名配置（30分钟）

#### 2.1 购买域名

推荐平台：
- Cloudflare Registrar（最便宜）
- Namesilo
- 阿里云/腾讯云（国内备案麻烦）

#### 2.2 DNS 配置

在 Cloudflare 添加 A 记录：

| 类型 | 名称 | 内容 | 代理状态 |
|:---|:---|:---|:---|
| A | api | 149.28.143.114 | 仅 DNS |
| A | pay | 149.28.143.114 | 仅 DNS |

#### 2.3 部署 Nginx Proxy Manager

```bash
mkdir -p /opt/npm && cd /opt/npm

cat > docker-compose.yml << 'EOF'
version: '3'
services:
  npm:
    image: jc21/nginx-proxy-manager:latest
    container_name: nginx-proxy-manager
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
      - "81:81"
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt
EOF

docker compose up -d
```

访问 `http://149.28.143.114:81`
- 默认账号：`admin@example.com`
- 默认密码：`changeme`

#### 2.4 配置反向代理

1. Proxy Hosts → Add Proxy Host
2. Domain: `api.yourdomain.com`
3. Scheme: `http`, Forward: `127.0.0.1`, Port: `3000`
4. SSL → Request new certificate → Force SSL

### 阶段四：支付系统（2小时）

#### 4.1 方案选择

**推荐：彩虹易支付 + New-API 内置充值**

New-API 已内置易支付对接功能，只需配置商户信息。

#### 4.2 注册易支付商户

1. 访问易支付官网（搜索"彩虹易支付"）
2. 注册商户账号
3. 获取：
   - 商户 ID（pid）
   - 商户密钥（key）
   - 支付网关地址

#### 4.3 配置 New-API 支付

在 New-API 后台 → 系统设置 → 支付设置：

```
支付方式：易支付
商户ID：你的 pid
商户密钥：你的 key
支付网关：https://pay.example.com
回调地址：https://api.yourdomain.com/api/user/epay/notify
```

#### 4.4 配置充值套餐

在「充值」页面添加套餐：

## 五、备份策略

### 5.1 数据备份

```bash
# 创建备份脚本
cat > /opt/backup.sh << 'EOF'
#!/bin/bash
DATE=$(date +%Y%m%d)
BACKUP_DIR=/opt/backups

mkdir -p $BACKUP_DIR
cp -r /opt/new-api/data $BACKUP_DIR/new-api-$DATE
tar -czf $BACKUP_DIR/new-api-$DATE.tar.gz $BACKUP_DIR/new-api-$DATE
rm -rf $BACKUP_DIR/new-api-$DATE

# 保留最近7天
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
EOF

chmod +x /opt/backup.sh

# 每日凌晨3点备份
echo "0 3 * * * /opt/backup.sh" | crontab -
```

## 八、常见问题

| 问题 | 解决方案 |
|:---|:---|
| 渠道测试 401 | 检查 API Key 是否正确 |
| 渠道测试 403 | 服务器 IP 被封，换地区 |
| 支付回调失败 | 检查回调地址是否正确 |
| SSL 证书申请失败 | 等待 DNS 生效，开放 80 端口 |
| 用户无法注册 | 检查注册功能是否开启 |
