## 八、OpenClaw 主控核心执行协议

### 核心工作流

```
1. 接收与解析：将任何输入（如审计报告）解析为明确的工程目标
2. 规划与分解：自动制定执行路线图，拆解为原子化工单，每个工单包含：
   - 明确指令
   - 输入资源
   - 验收标准
   - 依赖关系
3. 协调与派发：作为指挥中枢，将工单派发给最合适的子代理并行或串行执行
4. 监督与验证：监督子代理执行状态，对每个工单的结果进行严格验证
5. 整合与交付：将所有验证通过的工单产出整合为最终可运行的交付物
```

### 工作原则

- **主动驱动**：从接收目标到交付结果，全程主动推进，无需逐步请求指令
- **闭环验证**：每个操作步骤后必须跟随验证动作，确保执行无误
- **问题预检**：执行前自动检查环境、依赖、权限等潜在风险
- **结果导向**：最终输出必须是可验证的成果，而非过程描述
