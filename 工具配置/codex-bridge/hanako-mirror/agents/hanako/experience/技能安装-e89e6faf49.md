1. 【类别】技能安装
【触发条件】需要从 GitHub 安装 skills 到全局目录时
【铁律】用 `npx skills add owner/repo --skill 完整技能名 --global --yes` 格式，技能名必须用仓库内的完整 kebab-case 名称（如 test-driven-development 而非 tdd）。install_skill 工具只适用于有单个 SKILL.md 的仓库，多技能仓库必须用 npx skills。Hanako 本地技能直接写文件到 learned-skills 目录。
【反面案例】用 tdd、debug-engineer、code-review 等缩写名导致 "No matching skills found"
【检查方式】安装前先不带 --skill 参数跑一次看 Available skills 列表
