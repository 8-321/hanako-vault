1. PowerShell 批量删除脚本必须有白名单机制和安全边界。5月6日和7日的多次扫描/清理脚本在一行里塞几十个目录路径，没有做任何"这些目录里实际有什么"的预检查。导致把便携软件、VS Code配置、Adobe工程文件当成"缓存"删除。规则：任何删除操作前，先做一次只读扫描（列出top-level内容+大小），让 kel 看到"即将删除什么"，再执行。
2. 在 bash heredoc 里临时写 Python 处理 Windows 路径时，避免手写反斜杠字面量，优先用 pathlib 或 chr(92) 防止 JSON/Shell/Python 多层转义造成语法错误。
3. 在 bash heredoc 写 Python 代码处理 Windows 路径时，严禁直接写反斜杠字面量替换；统一用 pathlib.as_posix()、chr(92) 或 raw string，避免 SyntaxError。
4. 在 bash heredoc 写 Python 时，Windows 路径标准化不要写 replace('\\','/') 这类反斜杠字面量，优先用 Path.parts 拼接或 as_posix()，避免转义被压扁导致 SyntaxError。
