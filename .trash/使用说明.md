# HanakoVault 使用说明

## 这是什么

个人的 Obsidian 知识库。所有内容（日常笔记、AI对话、项目归档、技能库、自媒体、需求）都集中在这里，一个Vault管全部。

路径：

```
D:\小柯 Ke\HanakoVault
```

## 目录速览

| 目录 | 放什么 |
|---|---|
| `00 - 每日笔记/` | 每天的日记 |
| `对话记录/` | Codex / Hanako 对话存档 |
| `项目/` | 正在推进的项目 |
| `系统/` | Agent 规则、中转站配置、工具配置 |
| `技能/` | 收集和自建的 Skill |
| `公众号/` | 小柯的成长实验室相关内容 |
| `需求库/` | 产品/项目灵感待探索 |
| `AI学习知识库/` | AI 学习笔记 |
| `技术资料库/` | 技术参考文档 |
| `工作流/` | 项目执行流程 |
| `工具生态/` | 工具配置参考 |
| `备份索引/` | 自动备份记录和索引 |
| `模板/` | 笔记模板 |
| `回顾/` | 周记、月记 |
| `06 - 周期回顾/` | 周期复盘 |
| `收件箱/` | 待整理内容 |
| `附件库/` | 图片、文件附件 |
| `巡检/` | 系统巡检记录 |
| `hanako/` | Hanako 子 Vault 配置 |

## Git 同步

仓库地址：`https://github.com/8-321/hanako-vault`

每次修改后建议提交推送，保持 GitHub 备份和本地同步。

## 怎么找东西

1. 按目录分类直接翻阅
2. 用 Obsidian 搜索（Ctrl+Shift+F）
3. 查看 `主页.md` 获取总览

## 笔记规范

- 中文优先，通俗易懂
- 标题用完整描述，不缩写
- 空文件加占位文字（如 `📝 待探索`）
- 对话记录统一格式：`Codex YYYY-MM-DD 主题.md`
