# Codex 对话沉淀 Skill 规则入口

## 中文总结

Codex 以后会在每一个对话、每一个问题后，自行判断这次经验是否值得沉淀成可复用 Skill。值得沉淀时，会创建 Skill 文件夹，并同步到黑曜石。

## 细节解释

正式 Skill 已放在：

- Codex Skill：`D:\CodexHome\skills\kel-conversation-skill-distillation\SKILL.md`
- 黑曜石镜像：`D:\小柯 Ke\HanakoVault\系统\Skills\kel-conversation-skill-distillation\SKILL.md`
- 当前项目规则：`E:\1\New project 4\AGENTS.md`

这个规则不是把所有聊天都保存，而是只保存以后可能复用的工作方法、稳定偏好、流程、踩坑经验和自动化模式。一次性信息、隐私原文、账号密码、token、密钥不会沉淀。

## 重点

- 默认由 Codex 自行判断，不每次都问 Kel。
- 值得复用的内容才沉淀成 Skill。
- Skill 格式固定为：中文总结、细节解释、重点、触发场景、执行步骤、验证方式、安全边界。
- 正式 Skill 同步到 `系统/Skills`，这个收件箱文件只是为了让 Kel 在 Obsidian 里更容易看见入口。
