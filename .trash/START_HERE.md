# Obsidian 首次配置指南

> 打开 Vault 后按以下步骤操作，3分钟搞定。

---

## 第一步：开启社区插件

1. 左下角 **⚙️ 设置** → **社区插件**
2. 关闭 **安全模式**（点击"关闭安全模式"）
3. 点击 **浏览** 按钮

---

## 第二步：安装插件（共7个）

在社区插件浏览器中搜索并安装：

| 插件 | 搜索关键词 | 用途 |
|:---|:---|:---|
| **Dataview** | dataview | 对话记录查询、资料索引 |
| **Templater** | templater | 模板自动化 |
| **Calendar** | calendar | 日历视图 |
| **Obsidian Git** | git | 自动 Git 同步 |
| **Tag Wrangler** | tag wrangler | 标签批量管理 |
| **Icon Folder** | icon folder | 文件夹图标美化 |
| **Recent Files** | recent files | 最近打开文件 |

每个插件：搜索 → Install → Enable

---

## 第三步：启用 CSS 美化

1. **设置** → **外观** → 拉到底部 **CSS 代码片段**
2. 点击刷新按钮
3. 开启 **hanako-chat** 开关

这会让对话记录的用户消息显示为蓝色气泡，思考过程灰色折叠。

---

## 第四步：验证

1. 左侧文件列表 → 打开 **对话记录** 文件夹 → 随便点一个
2. 应该看到格式化的对话（蓝色用户消息 + 折叠的思考过程）
3. 试试 Dataview 查询：新建一个笔记，输入：

````
```dataview
TABLE date, title
FROM "对话记录"
SORT date DESC
```
````

---

## 配置说明

| 配置项 | 当前值 | 说明 |
|:---|:---|:---|
| 附件目录 | `附件库/` | 图片等附件统一存放 |
| 新文件位置 | `附件库/` | 新建文件默认位置 |
| 主题 | 暗色（Obsidian） | 可在设置→外观切换 |
| 强调色 | 紫色 #7c5cfc | 可自定义 |
| Git 自动同步 | 每10分钟 | 安装 Obsidian Git 后生效 |

## 快捷键

| 操作 | 快捷键 |
|:---|:---|
