# HanakoVault 结构清理

## 做了什么

11 个空壳目录删除，散落在根目录的 13 个 .md 文件归位到 `系统/` 或 `笔记/`。两处日记（`00-每日笔记` + `日记`）合并进 `日志/`。

## 新结构

```
HanakoVault/
├── 主页.md
├── 日志/          ← 唯一日记入口
├── 对话记录/       ← AI 对话归档（保留原名，同步脚本依赖）
├── 笔记/          ← 知识沉淀（AI调教、技术、工作流）
├── 项目/          ← 有交付物的项目
├── 回顾/          ← 周/月复盘
├── 巡检/          ← 五助手巡检
├── 系统/          ← Agent规则、工具、模板、中转站
├── 收件箱/        ← 碎片
└── 附件库/        ← 图片等附件
```

## 规则

- 文件来才建目录，不预建空壳
- 每篇笔记用统一 YAML frontmatter（date + tags）
- Hanako 自动观察对话，有产出就写笔记，不等指令
