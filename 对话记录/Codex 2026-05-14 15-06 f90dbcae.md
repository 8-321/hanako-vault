**2) 推荐页面结构**

主页面建议叫：**小柯灵感库 · 需求库**。第一屏直接是工具，不做大而空的品牌 Hero。

结构：

1. 顶部细导航  
   左侧：小柯灵感库 · 需求库  
   中间：`灵感库 / 需求库 / 从灵感生成需求 / 最近更新`  
   右侧：搜索框 + “记录灵感” + “新建需求”

2. 第一屏工作台  
   左侧大标题：`把闪念变成可执行的小项目`  
   下方三枚入口按钮：`找灵感`、`写需求`、`转成行动`  
   右侧放“今日待整理”：最近灵感、未成形需求、可推进事项。

3. 双库主区  
   `灵感库`：用卡片瀑布/网格，字段为：来源、触发点、可复用角度、适合做什么、关联需求。  
   `需求库`：用更清晰的条目卡，字段为：目标、使用场景、当前状态、下一步、关联灵感。

4. 灵感转需求区  
   做成一条轻流程：`灵感捕获 → 提炼价值 → 写成需求 → 进入执行`。  
   这里可以复用 `.superpowers/brainstorm` 那种 A/B/C/D 选择卡，降低上手门槛。

5. 底部知识地图  
   按小柯风格分成：`AI成长实验 / 工具箱 / 内容创作 / 生活系统 / 产品想法 / 认知破局`。

**3) 组件建议**

- `LibraryTabs`：灵感库/需求库切换，保持轻，不做复杂后台菜单。
- `QuickCapture`：一句话输入框，支持“灵感”或“需求”二选一。
- `InspirationCard`：更自由，像实验日志卡，有标签、来源、摘录、可转化按钮。
- `RequirementCard`：更落地，显示目标、状态、下一步。
- `BridgePanel`：把灵感一键整理成需求的中间面板。
- `StatusStrip`：复用现有主页的状态条气质，显示“本周新增 / 待转化 / 已执行”。
- `TimelineMini`：用来展示需求从想法到落地的演化，呼应现有 `Timeline` 风格。

**4) 不建议做什么**

- 不建议做成飞书/Notion/机构后台那种左侧大菜单 + 大表格 + 一堆筛选器，会削弱“小柯个人实验室”的气质。
- 不建议第一屏放纯宣传 Hero，用户进来应该马上能记录、查找、转化。
- 不建议堆太多分类层级，小白会不知道点哪里；一级分类控制在 5-6 个。
- 不建议全黑科技感过重。可以保留深色、金色、终端感，但灵感/需求卡片要更温暖、可读、像个人工作台。
- 不建议直接复刻 `feishu-page.html` 的复杂结构，它适合做内容来源参考，不适合做主页面 UI 基础。
