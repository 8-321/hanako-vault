定位：高能瞬间和“做成项目”的爽点。  
适合形式：强开头短视频、过程反转、屏幕纪录、真人解释。  
不适合：慢热散文感。

样例 1  
开头：`我发现很多人不是没想法，是想法一辈子没进过现实。`  
内容：抽卡项目从 0 到链接，40 秒打完。  
形式：快节奏剪辑 + 你一句钉子句。

样例 2  
开头：`我不是计算机专业，但我还是把这个东西做出来了。`  
内容：讲“专业不对口”怎么不是阻碍，而是项目视角的起点。  
形式：强出镜 + 屏幕插片。

样例 3  
开头：`做项目最危险的一步，其实不是技术。`  
内容：讲“本地能跑”和“真实存在”不是一回事。  
形式：口播 + 页面展示。

**B站**
定位：你的项目纪录片基地。  
适合形式：项目纪录、成长纪录、观察者旁白、半叙事半教程。  
不适合：纯口播知识点合集。

样例 1  
标题：`我用 Cursor 做了一个抽卡小程序，然后把它扔进了现实`  
内容：完整讲想法、过程、卡点、结果、反思。  
形式：8-12 分钟项目纪录片。

样例 2  
标题：`一个普通大学生，怎么把零散兴趣慢慢接成一个系统`  
内容：从你的网站、内容、AI、小项目讲你的“多线程系统”。  
形式：中出镜纪录 + 旁白。

样例 3  
标题：`为什么我开始把成长写成实验，而不是感悟`  
内容：把公众号那篇改成视频版。  
形式：纪录短片感，不要纯讲台式口播。

---

**知乎**
定位：判断和方法沉淀地。  
适合形式：回答、长答、方法论文章。  
不适合：太强个人宇宙包装。

样例 1  
问题：`普通人做项目，最容易卡在哪一步？`  
回答：重点讲“想法无法进入现实”的那一步。  
形式：结构化长答。

样例 2  
问题：`AI 对普通大学生最大的价值是什么？`  
回答：不是替你变厉害，而是帮你把模糊念头推到现实。  
形式：观点型回答。

样例 3  
问题：`为什么有些人想法很多，但始终做不出东西？`  
回答：讲任务压缩、最小项目、反馈回路。  
形式：经验解释型回答。

**B 面探索形态**

你说你喜欢探索，所以我不给你只配“普通图文 + 普通视频”。

可以插进来的高辨识形式：

- `条漫图文`
  适合小红书 / 公众号副栏。内容是“一个想法怎么从脑内逃到现实”。
- `伪纪录片动画`
  适合 B 站 / 视频号。把“观察者档案”“项目生成”做成轻科幻包装。
- `屏幕 + 手写板混剪`
  适合抖音 / 视频号。你说一句判断，屏幕上跑项目，手写层标关键点。
- `项目卡片`
  适合公众号 / 小红书 / 知乎。每个项目一张标准化卡片：起点、推进、结果、洞察。

**起步顺序**

别六个平台同时爆冲。先这样：

1. 先发公众号主文：`为什么我开始把成长写成实验日志`
2. 同主题拆成视频号短讲和小红书图文
3. 再发抽卡程序的抖音/B站/知乎版本
4. 跑出第一轮后，再开第二个项目主题

这样你不是在“填平台”，而是在“让同一个主线长出不同形态”。
