## 一、Obsidian 同步方案（核心推荐：Git）

### 为什么不用 iCloud / OneDrive

| 方案 | 问题 |
|:---|:---|
| **iCloud** | macOS 独占，Windows 不支持。跨平台玩家直接出局 |
| **OneDrive** | 已知冲突问题：多人/多设备编辑同一文件会产生 `.OneDrive-conflict` 副本，Obsidian 的双链和块引用极依赖文件唯一性，一旦冲突，笔记关联会断掉 |
| **Git + GitHub** | 版本控制、冲突可视化、多设备增量同步、免费。**是 Obsidian 社区公认的正确答案** |

### 实操步骤（Git + GitHub Desktop，Windows 全流程）

**第一步：创建 GitHub 仓库**
- 登录 github.com，新建一个 **private** 仓库，命名 `my-obsidian-vault`
- 不要勾选 README 和 .gitignore，Obsidian vault 自己管理这些

**第二步：安装 Git + GitHub Desktop**
```bash
# 用 winget 安装（Windows 10+ 自带）
winget install Git.Git
winget install GitHub.GitHubDesktop
```

**第三步：在 Obsidian 中初始化本地仓库**

打开 Obsidian → 你的 vault 目录 → 打开终端（在 vault 根目录）：

```bash
git init
git remote add origin https://github.com/你的用户名/my-obsidian-vault.git
```

**第四步：写 .gitignore（关键！）**

在 vault 根目录创建 `.gitignore`，过滤掉不需要同步的文件：

```
# Obsidian 运行时缓存（不要同步）
.obsidian/workspace
.obsidian/cache
.obsidian/.app2

# 图片/附件（如果多设备流量敏感可以排除）
# attachments/
```

> ⚠️ `.obsidian/*.json`（插件配置）**必须保留并同步**，这样换设备后 Obsidian 插件状态全部保留，开箱即用。

**第五步：首次推送**

```bash
git add .
git commit -m "Initial vault"
git branch -M main
git push -u origin main
```

**第六步：新设备恢复**

在新电脑上：
1. 安装 Obsidian + GitHub Desktop
2. Clone 仓库到本地 → 用 Obsidian 打开该文件夹
3. `.obsidian/plugins/` 里的插件全部保留配置，重启 Obsidian 后自动加载

## 三、自建模型中转站（One-API）

### 为什么选 One-API

你工作空间里已有的 `New-API` 就是这个思路。**One-API**（songquanpeng/one-api）是目前社区最活跃的开源方案，前人已经踩过所有坑：

- **Docker 一键部署**，换电脑重装只需 `docker run` 一行
- **模型映射**，一个 API Key 对接所有平台，下游 AI Agent 只配一个地址
- **配额管理**，不超支
- **Git 管理配置**，迁移时导出导入

### 推荐部署方式

**第一步：选 VPS**

| 选项 | 适合人群 |
|:---|:---|
| **境内云（腾讯云/阿里云）** | 需要备案，但延迟最低，访问国内模型（DeepSeek/智谱）最快 |
| **境外 VPS（rackNerd/lowendbox）** | 不需要备案，访问 OpenAI/Anthropic/Google 延迟低，年付 $10-30 |

> ⚠️ 如果用境外 VPS 访问国内模型，需要走代理，架构会变复杂。建议先确认你最常用的模型在哪边。

**第二步：Docker 一键部署**

```bash
# 在 VPS 上运行（Ubuntu/Debian）
docker run --name one-api -d \
  --restart always \
  -p 3000:3000 \
  -e TZ=Asia/Shanghai \
  -v /home/ubuntu/data/one-api:/data \
  justsong/one-api
```

启动后访问 `http://你的VPS_IP:3000`，用 `root / 123456` 登录，**立刻改密码**。

**第三步：配置你已有的渠道**

根据你工作空间里的 `New-API_智慧调度指挥部_最终交付手册.md`，把你现有的渠道配置录入：
- 77Code（主力中转）
- MiniMax TokenPlan（套餐）
- DeepSeek 官方

**第四步：迁移时保留配置**

One-API 的数据存在 `/data` 目录，备份整个目录：

```bash
# 备份
tar -czf one-api-backup.tar.gz /home/ubuntu/data/one-api

# 迁移到新机器
scp one-api-backup.tar.gz new-server:/home/ubuntu/
tar -xzf one-api-backup.tar.gz
docker run ... # 重新运行，/data 挂载路径相同即可
```

**第五步：AI Agent 调用方式**

```
Base URL: http://你的VPS_IP:3000/v1
API Key:  你在 One-API 里生成的令牌
```

任何支持 OpenAI API 格式的 AI 工具都能用，换电脑换 Agent 不丢。
