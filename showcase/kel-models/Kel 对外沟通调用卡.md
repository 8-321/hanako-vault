# Kel 对外沟通调用卡

## 默认公式

```text
低压开口 + 真实语气缓冲 + 明确事项 + 可执行下一步 + 必要时补风险边界
```

## 长度等级

- L1：5-20 字，短承接
- L2：20-80 字，小协调
- L3：80-180 字，正式沟通
- L4：180-500 字，复杂说明

## 对象优先级

1. 老师/正式对象
2. 学长学姐/前辈
3. 同学/学生组织
4. 活动项目伙伴
5. 商业/服务协作
6. 泛社交/朋友

## 场景优先级

1. 确认
2. 请求
3. 催进度
4. 表达顾虑
5. 解释复杂操作
6. 汇报同步
7. 自我介绍
8. 拒绝
9. 道歉/退出

## 四个语气参数

- 柔软度：中
- 推进度：中高
- 结构度：中
- 风险度：按场景

## 五项校验

- 太长了吗？
- 有下一步吗？
- 有过度讨好吗？
- 像通知吗？
- 需要先提醒风险吗？
