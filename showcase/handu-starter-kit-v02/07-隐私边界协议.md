# 含渡启动包 v0.2｜隐私边界协议

> 原则：先保护主权，再谈效率。

## 永远不要直接上传的内容

```text
身份证、手机号、地址、银行卡、验证码
微信原始聊天记录
联系人列表
日记原文
私人照片和语音
合同原件
账单原件
第三方隐私材料
未脱敏项目资料
```

## 可以脱敏后使用的内容

```text
公开资料
学习困惑
项目卡点
内容选题
去掉身份信息后的案例
用自己的话概括后的聊天内容
```

## 脱敏规则

```text
真实姓名 → A 同学 / 某老师 / 合作方
具体学校 → 某高校
具体金额 → 小额 / 中额 / 高额
原文聊天 → 先概括再用
图片语音 → 先转文字摘要
```

## 发给 AI 之前先问自己

1. 有没有第三方隐私？
2. AI 真的需要原文吗？
3. 我能不能只给摘要？
4. 发出去后会不会伤害任何人？
5. 这段材料适合进长期知识库吗？

## 进入长期系统前再问一次

1. 一年后还值得看吗？
2. 它是否帮助未来判断？
3. 它是否已经脱敏？
4. 它会不会只是情绪产物？
