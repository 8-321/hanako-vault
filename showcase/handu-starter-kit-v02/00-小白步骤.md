# 含渡启动包 v0.2｜小白步骤

> 如果你现在脑子很乱，不要先看全部。先照这 5 步走。

## 只做这 5 步

### 第 1 步：打开入口页

新建一个文件，名字叫：

```text
我的含渡入口页.md
```

把下面三句话写进去：

```text
我现在最乱的一件事：
我真正想要的结果：
我今天能做的一步：
```

### 第 2 步：判断你最乱的类型

打开 `01-诊断表.md`，给六种混乱打分。

只找分数最高的那一类。

不要同时处理六类。

### 第 3 步：选一个主线

打开 `04-主线裁决卡.md`，把你现在最重要的一件事写进去。

然后只做一个裁决：

```text
留 / 停 / 删 / 转 / 试
```

### 第 4 步：做一个 72 小时动作

打开 `05-72小时行动卡.md`，写一个三天内能完成的小动作。

要求：

```text
小
具体
能做完
能验证
```

### 第 5 步：一周后复盘

打开 `06-周复盘卡.md`，回答这四句：

```text
我更清楚了吗？
我更稳了吗？
我更少重复劳动了吗？
我推进了一个真实动作吗？
```

## 小白版只记住一句话

```text
先写乱的，再判断，再做一个小动作，再复盘。
```

## 你现在不用懂全部

你不用先懂：

- 五步法
- 分类系统
- 四层一中枢
- 五个智能体
- Vault 和 KelWorkspace 的区别

你现在只要会做这件事：

```text
把混乱写下来，选一件事，只推进一个小动作。
```
