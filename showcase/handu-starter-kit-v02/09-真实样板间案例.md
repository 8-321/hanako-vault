# 含渡启动包 v0.2｜真实样板间案例

> 这是一个方法样板，不是人生复制题。

## 初始状态

一个人同时在处理：

```text
AI 系统
微信导出
Obsidian Vault
Codex 工具链
公众号内容
项目整理
五智能体协作
品牌命名
```

如果全部放在一起，结果就是混乱。

## 第一步：先诊断

先判断主混乱是什么。

可能是：

```text
信息混乱
项目混乱
身份混乱
行动混乱
决策混乱
关系混乱
```

## 第二步：压出主线

主线压成一句：

```text
用 AI、知识系统和自我观察，把混乱经验转化为认知裁决、行动路径和可复用系统。
```

## 第三步：分层归位

```text
原始材料 → 本地
工作草稿 → KelWorkspace
长期定稿 → Vault
可执行任务 → Codex
高风险裁决 → Hanako
```

## 第四步：做最小成品

先做：

```text
含渡启动包
```

而不是大平台、大课程、大社群。

## 第五步：验证结果

看三件事：

1. 是否更清楚
2. 是否更稳
3. 是否推进了真实动作
