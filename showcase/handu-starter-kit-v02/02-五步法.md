# 含渡启动包 v0.2｜五步法

> 含渡不是让你多做一点，而是让你更清楚地分层、裁决和行动。

## 五步：观、定、渡、行、归

### 1. 观

看清当前混乱属于哪一类。

输出：

```text
当前主混乱类型
目前有哪些材料
哪些是事实，哪些是感受
```

### 2. 定

定主线和边界。

输出：

```text
这件事到底要解决什么
什么先做，什么后做
什么暂时不碰
```

### 3. 渡

把材料分层归位。

输出：

```text
进原始材料层的
进工作区的
进长期知识库的
可以直接删除或停止维护的
```

### 4. 行

只做一个能在 72 小时内验证的动作。

输出：

```text
一个具体动作
预计时长
验证方式
```

### 5. 归

复盘结果，决定留、停、删、转。

输出：

```text
留下什么
停止什么
删除什么
转成什么结构化资产
```

## 五步法的硬规则

1. 观不等于分析过度
2. 定不等于永远正确
3. 渡不等于全部保留
4. 行不等于大动作
5. 归不等于美化复盘
