# 含渡启动包 v0.2｜诊断表

> 先判断你属于哪种混乱，再决定怎么用系统。

## 评分方法

每项 0 到 2 分：

```text
0 = 基本没有
1 = 偶尔出现
2 = 经常出现
```

## 六种混乱

### 1. 信息混乱

表现：

- 材料太多，找不到重点
- 资料散在多个地方
- 读了很多，但没形成判断

### 2. 项目混乱

表现：

- 同时开很多项目
- 没有明确优先级
- 计划很多，推进很少

### 3. 身份混乱

表现：

- 不清楚自己现在是谁
- 方向经常被外界牵着走
- 想成为什么和实际在做什么不一致

### 4. 行动混乱

表现：

- 知道要做什么，但总拖延
- 一忙起来就乱
- 没有固定推进节奏

### 5. 决策混乱

表现：

- 面对选择很难下决定
- 总想等更充分的信息
- 选完后又反复怀疑

### 6. 关系混乱

表现：

- 人际边界不清
- 容易被情绪牵着走
- 沟通后总有消耗感

## 计算方式

把每项分数加起来，分数最高的就是当前主混乱。

## 结果解释

### 信息混乱最高

先不要急着做决定，先分层归档。

### 项目混乱最高

先砍项目，再推进项目。

### 身份混乱最高

先定主线，不急着扩张。

### 行动混乱最高

先做节奏，不先做更大计划。

### 决策混乱最高

先裁决，再执行，不要继续收集无效信息。

### 关系混乱最高

先定边界，再谈协作。

