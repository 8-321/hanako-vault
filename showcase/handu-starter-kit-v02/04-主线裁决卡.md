# 含渡启动包 v0.2｜主线裁决卡

> 用于决定：留、停、删、转、试。

## 决策对象

```text
[项目、文件、习惯、内容、合作、系统模块]
```

## 五问

1. 它服务主线吗？
2. 它能在 7 天内形成最小结果吗？
3. 它会减少未来重复劳动吗？
4. 它是否增加库存和维护负担？
5. 它是否值得进入长期系统？

## 五种裁决

### 留

有长期价值，进入 Vault 或长期模块。

### 停

暂时不做，但不删除。

### 删

不再需要，且继续留着只会制造噪音。

### 转

从一种形态转成另一种形态，例如：

- 材料转摘要
- 草稿转模板
- 项目转案例
- 经验转方法

### 试

只做一次最小验证，不直接长期化。

## 裁决输出

```text
我对这个对象的裁决是：
理由是：
下一步是：
复盘时间是：
```
