# 造字司 · Demo 0.1

一个独立网页互动游戏原型。主题是汉字造字、会意与万物生成。

## 打开方式

直接双击：

```text
D:\Hanako\zaozisi-demo\index.html
```

或在本目录启动本地服务：

```bash
python -m http.server 8777
```

然后打开：

```text
http://127.0.0.1:8777/index.html
```

## 当前玩法

把左侧字根拖入中央墨池，系统会按会意规则生成新字。

已支持组合：

| 组合 | 结果 |
| --- | --- |
| 日 + 月 | 明 |
| 木 + 木 | 林 |
| 林 + 木 | 森 |
| 木 + 木 + 木 | 森 |
| 人 + 木 | 休 |
| 火 + 火 | 炎 |
| 水 + 月 | 湖 |

## 技术

- HTML
- CSS
- JavaScript
- GSAP 本地文件：`vendor/gsap.min.js`

## 设计方向

不是古风皮肤，而是把汉字构形转成互动机制。玩家不是回答知识题，而是通过拖拽、组合、点化，生成自己的山海字卷。
