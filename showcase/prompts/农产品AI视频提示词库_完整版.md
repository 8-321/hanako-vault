## 零、农产品视频的核心逻辑

农产品视频跟普通产品视频最大的区别：**卖的不是「好看」，是「好吃」「新鲜」「放心」**。

观众点开一条农产品视频，潜意识里只关心三件事：

```
1. 这东西从哪来的？（产地信任）
2. 它新鲜/好吃吗？（感官刺激）
3. 我买了怎么用？（实用价值）
```

因此农产品 Prompt 需要额外强调四个维度：

| 维度 | 关键词 | 作用 |
|-----|--------|------|
| 新鲜度 | 水珠、晨露、刚摘、汁水、脆嫩 | 触发「想吃」的生理反应 |
| 自然感 | 阳光、泥土、藤蔓、山间、手工 | 建立「原产地直发」的信任 |
| 质感 | 光泽、纹理、切面、掰开、拉丝 | 用视觉传递触觉和味觉 |
| 烟火气 | 下锅、翻炒、蒸汽、摆盘 | 完成「从田间到餐桌」的叙事闭环 |

**万能公式（农产品特化版）：**

```
【运镜】+【农产品主体】+【新鲜度信号】+【自然环境】+【光线/质感】+【画质】
```

示例：
```
微距特写缓慢推进，刚摘下的大红番茄表面挂着晨露水珠，
清晨菜园柔光逆光穿透叶片，果实光泽饱满，电影感，4K
```

| 2 | **慢动作定格** | 让「瞬间」变成「事件」：汁水飞溅、果蒂分离、刀切入肉 | `慢动作，一刀切开水蜜桃，果汁呈弧线飞溅定格半空` |
| 3 | **环绕拍摄** | 展示产品的每一个角度，适合「整颗」「整体」展示 | `缓慢环绕，一颗完整榴莲在木台上旋转，外壳尖刺细节` |
| 4 | **俯拍拉远** | 从单颗特写到满筐全景，完成「量感」的叙事 | `俯拍从一颗红枣拉到满竹筛，红枣铺满画面如红色海洋` |
| 5 | **低角度仰拍** | 赋予农产品「被仰望」的仪式感，适合果树、藤架、人物采摘 | `低角度仰拍，人物伸手摘高处芒果，蓝天绿叶金黄果实` |
| 6 | **贴地推进** | 展示土壤、根部、地面细节，传达「从土里来」的真实 | `贴地推进，镜头沿泥土田埂向前，两侧是结满果实的植株` |
| 7 | **跟拍（追踪）** | 跟随人物在田间走动，制造「带你来看」的临场体验 | `稳定跟拍，新农人挎篮走进果园，边走边摘边对镜头介绍` |
| 8 | **航拍下降** | 从「上帝的视角」降落到人眼高度，展示产地全貌→近景 | `航拍从云雾中下降，逐渐露出山腰茶园，降落到采茶人身边` |
| 9 | **延时摄影** | 展示生长、日出、花开等时间维度，突显「自然的力量」 | `固定延时，同一株植物从日出到日落，光影在叶片上流转` |
| 10 | **手持微晃** | 真实感、临场感、不做作，适合Vlog式和农人自述 | `手持轻微晃动，跟着农人走进鸡舍捡还温热的鸡蛋` |
| 11 | **水中镜头** | 水果/蔬菜入水的瞬间特别有「清澈、干净」的暗示 | `沉入水中，一篮樱桃没入山泉清水，气泡从果间升起` |
| 12 | **门缝/叶间窥视** | 制造「发现了什么」的探索感，适合开场制造悬念 | `透过树叶缝隙窥视，远处是一片挂满果实的果园，缓慢拉近` |
| 13 | **拉远露出全景** | 从细节到全貌的揭示，适合「远不止这些」的量感表达 | `从一颗柑橘特写缓慢拉远，露出整棵树→整片果园→远山` |
| 14 | **垂直上升** | 从地面升到空中，适合「这片土地」的宏大结尾 | `镜头从田埂垂直上升，田地→村庄→山脉→云层，渐远` |
| 15 | **第一人称（POV）** | 让观众成为采摘者/烹饪者/品尝者，代入感最强 | `第一人称视角伸手摘下一颗苹果，在衣服上擦一擦，咬下` |

## 五、完整脚本模板 · 3 种经典结构

### 模板 A：爆款带货 15 秒

```
镜头1（0-3秒）: 微距推进，产品在画面中央，一滴水/汁沿表面滑落，钩子
镜头2（3-7秒）: 切开/掰开/撕开的慢动作，汁水飞溅，感官高潮
镜头3（7-11秒）: 整筐/满盘展示，环绕或俯拍拉远，展现量感
镜头4（11-15秒）: 第一人称POV咬一口/夹一块送到镜头前 + 结束画面带品牌名
```

### 模板 B：产地溯源 30 秒

```
镜头1（0-5秒）: 航拍下降，云雾中露出产地的全貌，建立「好地方」
镜头2（5-10秒）: 跟拍老农/新农人在田间走，自然光，人物信任感
镜头3（10-15秒）: 手部特写慢动作采摘，现摘现发的信息
镜头4（15-20秒）: 微距展示产品细节：露珠、纹理、颜色
镜头5（20-25秒）: 切开/掰开产品，展示内部质感
镜头6（25-30秒）: 一家人/团队捧着产品合影式构图，品牌名浮现
```

### 模板 C：品牌故事 60 秒

```
镜头1（0-8秒）:   黑白老照片叠化：祖父辈在这片土地上
镜头2（8-15秒）:  转彩色，现在的新农人接过锄头/走进果园
镜头3（15-25秒）: 主人公面对镜头自述（或内心旁白），手持跟拍她/他在田间
镜头4（25-35秒）: 采摘、筛选、打包的工作细节快剪，节奏从慢到快
镜头5（35-45秒）: 慢下来：特写产品细节，光线温暖
镜头6（45-55秒）: 一家人/团队围坐分享食物，笑声，暖色黄昏
镜头7（55-60秒）: 俯拍拉远，从餐桌升到整个村庄/田野，品牌Slogan
```

## 六、平台适配建议

| 平台 | 视频时长 | 最佳运镜 | 特别提示 |
|-----|---------|---------|---------|
| **抖音** | 7-15秒 | 微距推进 + 慢动作爆汁 + POV品尝 | 前3秒必须出爆点（切开/掰开/咬开），不要铺垫 |
| **快手** | 15-30秒 | 手持跟拍 + 环绕展示 + 老铁直面镜头讲述 | 真实感>精致感，带方言口播比无声配乐转化好 |
| **视频号** | 30-60秒 | 航拍下降 + 延时摄影 + 品牌故事结构 | 中老年用户多，「产地」「生态」「传统」是信任关键词 |
| **小红书** | 15-30秒 | 俯拍极简 + 微距质感 + 高饱和色彩 | 画面要「好看」到让人想截图，构图和色彩是第一生产力 |
| **淘宝/拼多多** | 15-30秒 | 环绕360° + 切开展示 + 量感堆叠 | 价格信息可以和产品特写叠在一起，信息密度要高 |

### 各平台适配的 Prompt 差异

同一颗苹果，不同平台的写法：

```
抖音：微距推进慢动作，苹果切开的瞬间汁水向镜头炸开，高饱和色彩，冲击力，3秒必爆

快手：手持走近苹果树，大哥伸手摘一颗在衣服上蹭蹭就咬，真实自然，老铁们看这脆度

视频号：航拍下降穿过晨雾，露出烟台北纬37°苹果园，红富士挂满枝头，自然成熟不催红

小红书：俯拍极简，一颗红苹果置于米白亚麻布上，侧光勾勒轮廓，高级感，适合截图
```

## 七、Prompt 自检清单

写农产品 Prompt 之前，过一遍这 6 个问题：

```
□ 镜头动了没有？（运镜指令是否明确）
□ 新鲜度信号有没有？（水珠/露水/泥土/汁水/热气 至少一个）
□ 光线说清楚了吗？（逆光/侧光/柔光/金色时刻）
□ 有声音感的视觉暗示吗？（水声/切菜声/咬下去的声音→用画面暗示）
□ 环境有信息量吗？（不是纯色背景，而是果园/菜地/厨房/自然）
□ 一条 Prompt 只有一个主运镜 + 一个辅助变化吗？
```

---

> 📌 **使用建议**：
> 1. 先确定品类，从第一章找对应提示词作为基础
> 2. 再确定场景，从第二章选择镜头结构
> 3. 用第三章的 15 种专属运镜替换/增强镜头运动
> 4. 把第四章的关键词嵌入 Prompt 的环境和光线描述中
> 5. 最后按第五章的模板排好镜头顺序
> 6. 对照第六章的平台特性做最后调整
>
> 💡 **农产品视频的终极心法**：观众刷到一条农产品视频时，他/她在 3 秒内决定「划走」或「停下来」。这 3 秒里起作用的东西叫「感官暗示」——水珠让你觉得新鲜，汁水让你觉得好吃，泥土让你觉得踏实。Prompt 不是描述产品，是**编码感官**。
