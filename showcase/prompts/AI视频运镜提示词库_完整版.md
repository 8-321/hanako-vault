## 零、万能公式（先记住这个）

```
【镜头类型】+【运镜方式】+【速度/节奏】+【主体】+【环境】+【氛围/光线】+【画质感受】
```

**简化版**：
```
主体 + 怎么动 + 动得多快 + 环境怎么配合
```

**一条黄金原则**：一个镜头只保留 **1 个主运镜 + 1 个辅助变化**。动作一多，模型大概率乱。

## 一、镜头运动 · 13 条

> 镜头怎么走 = 观众怎么感受。你不说，模型就自己脑补，结果大概率翻车。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 缓慢拉近 | Slow push-in | 画面从全景逐渐收窄，焦点越来越集中到主体上，产生「正在靠近」的代入感。观众注意力被引导到细节，适合揭示情绪或关键信息 |
| 2 | 缓慢拉远 | Slow pull-out | 画面从近景逐渐退到远景，主体在画面中变小，环境信息逐步增多。带来「抽离」「告别」「孤独」的情绪，适合结尾或转场 |
| 3 | 向左平移 | Pan left | 镜头水平向左旋转，画面横向扫过场景。适合展示空间的宽度、跟随横向移动的主体、或做「交代环境」的建立镜头 |
| 4 | 向右平移 | Pan right | 同左平移但方向相反。阅读习惯上「向右 = 前进/未来」，在叙事中有微妙的心理暗示 |
| 5 | 摄影车推进 | Dolly in | 相机整体向前移动（非变焦），画面透视关系持续变化，背景与前景的距离感增强。比 push-in 更有「物理进入空间」的真实感 |
| 6 | 摄影车拉远 | Dolly out | 相机整体向后移动，主体留在原地，画面空间被「打开」。适合揭示主角所处的更大环境，或表达「被留下」的情绪 |
| 7 | 顶部俯拍下降 | Overhead dive | 镜头从正上方向下俯冲，类似无人机降落。从抽象的平面视角过渡到具体的空间视角，冲击力强，适合开场或场景切换 |
| 8 | 环绕拍摄对象一圈 | Full orbit | 镜头围绕主体做360°旋转。营造「审视」「沉浸」「仪式感」，适合展示人物气场、产品全貌、或时间凝固的戏剧时刻 |
| 9 | 手持移动 | Handheld movement | 模拟手持摄影机的轻微晃动，带来纪录片式的真实感和临场感。适合追逐、紧张、第一人称视角 |
| 10 | 快速拉近 | Quick push-in | 突然的快推，画面迅速逼近主体。制造惊吓、紧张、或「突然发现」的戏剧效果 |
| 11 | 镜头向下倾斜推进 | Tilt-down dolly-in | 镜头在向前推进的同时向下倾斜。从高处靠近低处的目标，视角带有压迫感或俯视的审视感 |
| 12 | 垂直上升镜头 | Vertical lift-up shot | 镜头垂直向上抬升，画面视野逐渐开阔。适合「升华」「宏大揭示」「从微观到宏观」 |
| 13 | 快速横向穿越 | Fast lateral pass | 镜头快速从一侧掠到另一侧，中间画面模糊。模拟高速物体经过的视觉冲击，适合动作场面或速度感转场 |

## 二、拍摄角度 · 13 条

> 角度决定观众与主体的权力关系：仰视 = 敬畏/压迫，俯视 = 掌控/渺小，平视 = 平等/亲密。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 平视角度 | Eye-level shot | 镜头与主体眼睛同高，最自然的视角。观众感觉与主体平等，亲近感强，适合对话、日常叙事 |
| 2 | 仰拍低角度 | Low-angle view | 镜头从下往上拍，主体显得高大、有力量或具威胁感。建筑仰拍有压迫感，人物仰拍有英雄感 |
| 3 | 顶部俯视 | Top-down view | 镜头从正上方垂直向下拍，画面呈平面化构图。适合展示布局、食物、桌面工作、或「上帝视角」的冷漠审视 |
| 4 | 鸟瞰视角 | Bird's-eye view | 高空俯瞰，画面中有明确的地面参照物。展现空间的全貌和尺度感，适合城市、自然风光、战争场面 |
| 5 | 斜对角角度 | Diagonal front angle | 从主体前侧方45°左右拍摄，画面有纵深感和方向感。最常用的「好看」角度，兼顾正面信息与立体感 |
| 6 | 侧面视图 | Side profile | 纯粹的正侧面，主体轮廓清晰。适合剪影、对话中的倾听者、或强调线条美 |
| 7 | 后背视角 | Rear view | 镜头在主体正后方，观众看到的与主体看到的一致。引导观众「跟角色一起看」，营造悬念—你不知道他/她的表情 |
| 8 | 过肩拍摄 | Over-the-shoulder | 镜头越过A的肩膀拍B。经典的对话镜头，既能看到说话者的反应，又保留了A的存在感 |
| 9 | 地面视角 | Ground-level view | 镜头贴近地面，视点极低。将日常场景「陌生化」，地面纹理被放大，适合表现速度感或微观世界 |
| 10 | 宽角仰视 | Wide upward angle | 广角镜头+仰拍，画面边缘有透视变形。主体被夸张放大，天空或天花板占据大部分画面，有漫画式的张力和冲击力 |
| 11 | 正下方仰角 | Worm's-eye perspective | 镜头从正下方向上垂直拍，类似虫子的视角。极端角度，主体底部被强调，有强烈的陌生化和幽默感 |
| 12 | 微斜仰角 | Slight upward diagonal | 轻微从下往上的倾斜视角。比正仰拍柔和，介于平视和仰视之间，微妙地赋予主体分量感而不刻意 |

## 三、构图距离（景别） · 12 条

> 距离控制观众「看到多少」与「感受到多少」。越近 = 越亲密/越压迫，越远 = 越客观/越疏离。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 脸部特写 | Facial close-up | 画面中只有面部，五官占据绝大部分。极度亲密或极度压迫，适合揭示微表情、眼泪、眼神变化 |
| 2 | 中景（腰以上） | Medium shot (waist up) | 人物腰部以上入画，是对话场景的标准构图。兼顾表情和手势，信息量均衡 |
| 3 | 全身照 | Full-body shot | 人物从头到脚完整入画。强调姿态、穿搭、与空间的关系，适合出场介绍或动作展示 |
| 4 | 手部特写 | Hands close-up | 画面集中在一双手上。手是第二张脸，适合表现紧张（攥拳）、温柔（轻抚）、劳作、或关键道具操作 |
| 5 | 极远景 | Extreme long shot | 主体在画面中极小，环境占绝对主导。表达「人在天地间的渺小」，适合史诗感、孤独感、或建立空间关系 |
| 6 | 多人构图 | Group frame | 两人以上的组合画面。关键在于人物之间的空间关系和视线方向，适合群像、对峙、或团队展示 |
| 7 | 远距观察 | Distant peek | 通过遮挡物（树枝、窗框、人群间隙）远距离窥视。制造「偷窥」「秘密观察」的叙事张力 |
| 8 | 部分脸部构图 | Partial face (chin or side) | 只拍半张脸或下巴以下。通过「不完整」激发观众的好奇和想象，有神秘感或疏离感 |
| 9 | 双人近景 | Two-person close-up | 两人同时处于近景，面部距离近。适合表现亲密关系或紧张对峙，两人之间的空气感很重要 |
| 10 | 脚部特写 | Foot close-up | 画面集中在脚部。暗示行走、停留、犹豫，或通过鞋的细节传递人物信息 |
| 11 | 肩部局部构图 | Shoulder detail frame | 只拍肩颈区域。介于特写和中景之间的暧昧距离，适合表现疲惫、肩上的负担、或肌肤质感 |
| 12 | 半身含环境 | Half-body with environment | 人物半身+环境信息同时呈现。兼顾人物状态和空间氛围，适合「人物在场景中」的建立镜头 |

## 四、人物镜头 · 13 条

> 人物镜头的核心是「动作 + 镜头反应」的组合，动作触发镜头运动，镜头运动反过来强化动作的情绪含义。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 窗前站立，镜头环绕 | Standing by window / Orbit shot | 人物静止站在窗前，镜头缓慢环绕。窗外光线在人物面部流转，有沉思、等待、或「被审视」的戏剧感 |
| 2 | 转身离开，背后推进镜头 | Turn and walk / Dolly-in from rear | 人物转身走向远处，镜头从背后缓慢推进。观众被「留在原地」，看着角色离去，有送别、遗憾、或追随的冲动 |
| 3 | 坐地沉思，俯拍慢拉远 | Seated on floor / Top pull-out | 俯拍坐在地上的人，镜头缓慢拉远上升。人物越来越小，空间越来越大，孤独感和沉思感递增 |
| 4 | 边走边讲，保持胸部中景 | Walking & talking / Mid close-up | 镜头始终与行走中的人物保持同步，构图稳定在胸部中景。经典的「边走边聊」跟拍，交流感强、节奏自然 |
| 5 | 躺下闭眼，拉近眼部 | Lying pose / Zoom on eyes | 人物躺下闭眼，镜头逐渐推进到眼部特写。进入内心世界的视觉隐喻，适合梦境、回忆、或情绪高潮 |
| 6 | 靠墙微笑，镜头略晃 | Lean on wall / Subtle handheld | 人物靠墙微笑，镜头略带手持微晃。随性、真实、不做作，像朋友抓拍的瞬间 |
| 7 | 回头凝视，镜头定格 | Look back / Static shot | 人物回头看向镜头，画面完全静止。打破第四面墙的瞬间，有「被发现」「被吸引」的张力 |
| 8 | 坐姿换腿，低机位仰视 | Seated leg switch / Low-angle | 从低角度仰拍人物坐着换腿的动作。仰角赋予人物气场，换腿的微小动作被放大为有意味的姿态 |
| 9 | 她抬头迎光，缓慢推近 | Face to light / Slow dolly-in | 人物抬头面向光源，镜头缓慢推进。光线逐渐照亮面部，推近强化了「觉醒」「希望」「启示」的情绪 |
| 10 | 快步走向镜头 | Brisk walk toward lens | 人物从远处快步走向镜头，直到充满画面。压迫感逐渐增强，适合出场、对峙、或决心已定的时刻 |
| 11 | 坐下瞬间画面跟进 | Sit down / Frame follows motion | 人物坐下的瞬间镜头同步微微下沉。动作与镜头的协同制造出「重力感」，画面有节奏呼吸 |
| 12 | 鞠躬后站起，镜头上扬 | Bow & rise / Upward tilt | 人物鞠躬后站起，镜头从下向上跟随。从谦卑到挺立的视觉弧线，有仪式感和情绪转变 |
| 13 | 站立调整头发，特写推进 | Adjusting hair / Close-up push | 人物站立整理头发的瞬间，镜头推进到面部特写。日常动作被镜头放大，产生亲密感和不经意间的美感 |

## 五、创意镜头 · 13 条

> 「创意镜头」打破常规物理视角。它们不是人眼能看到的画面，而是「摄影机作为超自然存在」才能捕捉的视角。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 快速穿越树林 | Fast fly-through in woods | 镜头以极快速度穿梭于树木之间，树干从两侧飞速掠过。模拟无人机或精灵视角，有速度感、自由感和探索感 |
| 2 | 贴着水面滑行 | Camera gliding near water surface | 镜头紧贴水面低空滑行，水面纹理清晰可见。视角极低，水的反光和波动充满画面，有清凉、流畅的感官体验 |
| 3 | 拉远同时升起俯瞰 | Pull-out + upward aerial view | 镜头从近景拉远的同时螺旋上升，最终达到鸟瞰高度。一次性完成「告别细节」到「看清全貌」的视觉旅程 |
| 4 | 空中旋转后定格 | Aerial spin freeze | 镜头在空中快速旋转后突然停在某个角度。制造眩晕感后的「顿悟时刻」，适合揭示关键信息或高潮定格 |
| 5 | 倒退拍摄角色背影 | Reverse dolly on subject's back | 镜头倒退移动，始终面对角色背影。角色在画面中不动，但背景不断变化，有「被命运推着走」或「时间流逝」的意味 |
| 6 | 从角落滑出隐藏镜头 | Hidden reveal from corner | 镜头从画面角落的遮蔽物后缓慢滑出，逐渐揭示场景全貌。经典的悬疑揭示手法，制造「被发现」或「秘密揭开」的瞬间 |
| 7 | 天花板视角俯看 | Ceiling top-down angle | 镜头仿佛嵌入天花板，垂直向下俯瞰房间。非人类的视角，带来偷窥感或审视感，适合表现人物的脆弱 |
| 8 | 鱼眼畸变镜头 | Fisheye distortion | 使用鱼眼效果，画面四周弯曲变形。主观感极强，适合表现迷幻、醉酒、梦境、或极端情绪 |
| 9 | 镜头穿越玻璃进入室内 | Through glass into room | 镜头仿佛没有实体，直接穿过玻璃窗进入室内。超自然的无缝穿越，有魔法感和流畅的空间转换效果 |
| 10 | 镜头下沉进入水中 | Sink-through into water | 镜头突破水面下沉入水，画面由清晰变模糊再变清晰。两个世界的切换，声音也从空气传导变为水下闷响 |
| 11 | 画面镜中反射转场 | Mirror reflection scene change | 通过镜子中的反射画面自然过渡到另一个场景。经典的「镜子转场」，两个空间通过反射面无缝衔接 |
| 12 | 时间静止后镜头环绕 | Time-freeze + orbit | 画面中一切静止（人物凝固、水滴悬停），镜头绕场景旋转。类似《黑客帝国》子弹时间，有超现实的视觉奇观感 |
| 13 | 倒影中构图反转 | Inverted framing in reflection | 画面从水洼/镜面中的倒影开始，然后翻转回正。世界先以镜像呈现再「纠正」，有哲学意味和视觉趣味 |

## 六、精准构图 · 12 条

> AI 视频生成中，构图指令需要明确「主体放在画面的哪个位置」。不说清楚，模型会默认居中，缺乏设计感。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 胸部以上正面构图 | Frontal medium close-up | 人物正面、胸部以上，面部居中偏上。最标准的「说话人头」构图，适合口播、独白、自我介绍 |
| 2 | 人物站在左1/3画面处 | Subject left-third placement | 主体占据画面左侧1/3，右侧留白。符合三分法，视线方向或运动方向留有空间，画面呼吸感好 |
| 3 | 后脑勺中景偏左 | Rear head, slightly left | 人物背对镜头，后脑勺占据画面左侧1/3。观众看不到主体的脸，注意力被引导到画面右侧或前方的景色 |
| 4 | 对角线人物站姿，背景虚化 | Diagonal pose / Soft background | 人物沿对角线方向站立，背景被浅景深虚化。画面有动感和纵深感，主体从背景中「跳出来」 |
| 5 | 手部特写，背景模糊 | Hands-in-focus / Blurred background | 对焦在手上，背景完全虚化。浅景深将注意力完全锁定在手部动作上，有触觉感和亲密感 |
| 6 | 群体中某人仰头看镜头 | Group + single upward gaze | 人群中只有一个人抬头看向镜头。焦点人物从群体中被「标记」出来，观众的注意力被引导到这个人身上 |
| 7 | 门缝间视角 | Peek through door crack | 画面两侧被门缝遮挡，只留中间一条竖长的可视区域。极端的框架式构图，偷窥感和悬念感极强 |
| 8 | 全身背影，阴影压暗 | Rear full-body / Subtle shadow | 人物全身背影，整体处于暗调或剪影中。不展示面部细节，用轮廓和姿态传达情绪，有神秘感和高级感 |
| 9 | 桌角对角线构图 | Table corner / Diagonal setup | 桌面的一角从画面左下延伸至右上，形成对角线引导线。画面有几何秩序感，适合产品展示或桌面场景 |
| 10 | 背景渐虚中保留人物清晰 | Soft background with subject sharp | 通过浅景深实现背景从清晰到模糊的渐变过渡。人物始终锐利，背景变成柔和色块，画面干净、专业 |
| 11 | 框架内构图（门、窗等） | Framed by doorway or window | 主体被门框、窗框、拱门等自然框架「框」在画面中。视线被强制聚焦到框内，层次感和形式感强 |
| 12 | 上方留白构图 | Top space emphasized frame | 主体位于画面中下部，上方大量留白。留白空间可以放标题文字，或单纯用空旷感制造情绪张力 |

## 七、动线镜头 · 13 条

> 「动线」指人物或物体的运动轨迹。动线镜头的核心是「镜头跟随运动」，拍摄的不是静止的画面，而是一段位移。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 相机低位沿人物行进方向前进 | Low tracking shot from rear | 低角度从人物后方跟拍其前进。地面纹理被放大，人物腿部占据画面主体，有行进中的力量感和目标感 |
| 2 | 穿过走廊向前推进 | Camera moving through narrow corridor | 镜头在狭窄走廊中匀速向前推进。两侧墙壁形成强烈的透视引导线，有「走向未知」「穿越」的叙事感 |
| 3 | 跟随人物头部平稳前进 | Stable head-level tracking | 镜头在人物头部高度平稳跟随，如同坐在滑轨上。画面极其稳定，适合展现主角的主观视点或平稳叙事 |
| 4 | 镜头从空中急速俯冲 | Aerial dive downward | 镜头从高空向地面急速俯冲，画面加速逼近。类似跳伞或鹰隼捕猎的视角，肾上腺素飙升的视觉冲击 |
| 5 | 斜向下滑入室内 | Diagonal slide-in | 镜头从高处沿对角线方向滑入室内空间。优雅、流畅的空间切入方式，比直接切画面更有设计感 |
| 6 | 拉远并环绕建筑外部 | Pull-out orbit around exterior | 镜头从建筑某处拉远，同时环绕建筑外侧旋转。一次性展示建筑的全貌和空间关系，适合地产、城市宣传 |
| 7 | 贴地推进 | Ground-level push-in | 镜头贴地面前推，地面纹理和微小物件被放大。接近昆虫视角，适合表现速度、微观世界、或紧张的匍匐前进感 |
| 8 | 跟随人物转过楼梯口 | Turn corner with subject | 镜头紧随人物转过楼梯拐角。拐角的瞬间画面从封闭到打开，有空间节奏的变化和「柳暗花明」的叙事感 |
| 9 | 摄像头从背后穿过走廊追踪 | Rear chase through hallway | 镜头在人物正后方追逐式跟拍，穿过走廊。第一人称追逐游戏的视角，紧张感和速度感并存 |
| 10 | 镜头从上方落地贴人物脚步 | Drop from above to feet-level | 镜头从高处落下，停在人物脚边的高度。从俯瞰到贴地的快速视角切换，有坠落感或「扎入场景」的沉浸感 |
| 11 | 穿梭树林光影斑驳之间 | Through dappled forest motion | 镜头在树林中穿行，阳光透过树叶形成斑驳的光影。光影的明暗交替本身就是视觉节奏，有诗意和梦幻感 |
| 12 | 镜头绕建筑旋转再转入窗口 | Circle exterior then pass through window | 镜头绕建筑外旋转一圈后，穿过窗口进入内部。外部到内部的一镜到底，有「探索」和「发现」的叙事快感 |
| 13 | 随人物骑行横向穿过画面 | Bike ride / Side pass | 镜头与骑行中的人物保持平行，横向扫过画面。侧跟拍摄的经典动线，速度感+横向空间延展 |

## 八、场景技巧 · 12 条

> 场景技巧关注的是「画面内的变化」和「镜头间的衔接」，它们让视频从「会动的图片」变成「有节奏的影像」。

| # | 提示词（中文） | Prompt (English) | 显示效果 |
|---|-------------|------------------|---------|
| 1 | 场景模糊转清晰 | Blur-to-clear transition | 画面从完全模糊逐渐变为清晰。经典的「醒来」「聚焦」「真相浮现」的视觉隐喻 |
| 2 | 穿过窗帘聚焦室内 | Through curtain / focus inside | 镜头从窗帘外穿过，对焦点从窗帘布转移到室内。前景的轻柔遮挡过渡到清晰的室内，有窥探和亲密感 |
| 3 | 保持机位一致做转场 | Angle-locked scene change | 固定机位不变，画面中的人物/场景发生变化（跳剪/匹配剪辑）。有时间的跳跃感，适合「同一个位置，不同时间」的叙事 |
| 4 | 灯光从暗变亮，人物走入 | Lighting shift + entrance | 场景从暗逐渐变亮，同时人物从画面外走入。灯光的「开灯」与人物出场同步，有舞台剧的仪式感 |
| 5 | 窗户反射内部画面 | Reflection showing interior | 不直接拍室内，而是通过窗户玻璃的反射来展示。间接的、碎片化的信息呈现，有窥视感和诗意 |
| 6 | 门打开时推进镜头 | Push-in as door opens | 门向外打开的同时镜头向前推进穿过门洞。开门动作和镜头运动同步，有「被邀请进入」的流畅感 |
| 7 | 使用长镜头不中断画面 | Continuous long take | 一条镜头不间断地拍摄完整场景。真实时间流逝感，观众的沉浸感不被剪辑打断，适合紧张、真实感强的段落 |
| 8 | 阴影中人物现身 | Shadow reveal / Subject emerges | 人物从阴影区域逐渐走入光线中。经典的「反派登场」或「真相大白」的视觉处理，戏剧性强 |
| 9 | 景别拉远露出全景空间 | Wide-out to reveal environment | 从近景逐渐拉远到全景，不断露出更多环境信息。每一层拉远都是一次「你以为的就这些吗？还有更多」的揭示 |
| 10 | 从一角慢慢移出展现场景 | Edge-to-center frame motion | 镜头从画面边缘向中心移动，逐渐揭示场景全貌。探索式的揭示，观众不知道下一秒会看到什么 |
| 11 | 构图中前景遮挡部分画面 | Foreground partially blocking frame | 前景有物体（树枝、栏杆、人肩）遮挡部分画面。增加画面层次感和「在场感」，模拟了人眼透过遮挡物观看的真实体验 |
| 12 | 光线移动引导画面节奏 | Lighting movement guides rhythm | 光线在画面中有规律地移动（车灯扫过、日光移动、手电筒光束）。光成为画面的「节拍器」，引导观众注意力的移动 |

## 九、按应用场景分类速查

### 🎯 想要代入感 → 用推进 / 跟拍 / 环绕
```
缓慢拉近 · 摄影车推进 · 跟随人物头部平稳前进 · 环绕拍摄对象一圈
```

### 🎯 想要疏离感 → 用拉远 / 固定镜头 / 顶视角
```
缓慢拉远 · 顶部俯视 · 极远景 · 远距观察 · 背部视角
```

### 🎯 想要高级感 → 用平移 / 小幅绕拍 / 慢镜头
```
向左/右平移 · 微斜仰角 · 斜对角角度 · 框架内构图 · 阴影中人物现身
```

### 🎯 短视频不晕 → 用竖屏轻推 / 轻移 / 低速变焦
```
缓慢拉近（中速） · 平视角度 · 胸部以上正面构图 · 边走边讲保持胸部中景
```

### 🎯 产品展示 → 用环绕 / 特写 / 光线引导
```
环绕拍摄对象一圈 · 手部特写 · 光线移动引导画面节奏 · 贴地推进
```

### 🎯 剧情短片 → 用动线镜头 + 人物镜头组合
```
转身离开背后推进 + 快步走向镜头 + 穿过走廊向前推进 + 门打开时推进镜头
```

## 十、适配中国平台的特别建议

### 即梦（Jimeng / Seedance）
- 即梦对**中文提示词**理解良好，直接用上面的中文版即可
- 建议在提示词末尾加上 `电影感，真实摄影质感，4K` 提升画质
- 即梦 3.0 运镜能力大幅提升，环绕、推进效果稳定

### 可灵（Kling）
- 可灵对**英文提示词**响应更精准，强烈建议中英双语输入
- 在提示词中明确指定 `camera movement: slow dolly in, stable, smooth`
- 可灵的「图生视频」模式对运镜指令的遵循度高于「文生视频」

### 豆包
- 豆包的视频生成对**简短清晰**的指令响应最好
- 一条提示词控制在 30 字以内（中文），把复杂的镜头拆成多个短提示词
- 建议用「简化版公式」：主体 + 怎么动 + 动得多快

### 通义万相（Wan2.2）
- 通义万相对**自然语言描述**的运镜理解较好
- 不建议用过于术语化的表达，用「镜头慢慢靠近」「画面缓缓后退」比「dolly in/out」效果好

## 十一、最佳实践 & 工作流

### 镜头设计顺序（从稳到花）
```
固定/轻推/轻拉 → 平移/跟拍 → 环绕/俯仰 → 复杂转场/Loop
```

### 一条镜头一条 Prompt
```
✅ 缓慢推进 + 背景虚化
✅ 轻微环绕 + 光影变化  
❌ 推进 + 拉远 + 环绕 + 急速摇镜 + 旋转
```

### 牛片收尾工作流
```
写 Prompt → AI 生成镜头 → 挑片 → AI配音 → 智能字幕 → 去水印 → 标题优化
```

### 从 LibTV 借鉴的全流程思路
```
剧本撰写 → 分镜脚本 → 角色设定 → 逐镜生成 → 剪辑合成 → 配音字幕 → 输出成片
```

## 十三、进阶：情绪-运镜对照表

| 想传达的情绪 | 推荐运镜 | 示例提示词 |
|------------|---------|-----------|
| 温暖/亲密 | 缓慢推进 + 平视 + 浅景深 | 缓慢拉近至面部特写，柔光，浅景深背景虚化 |
| 孤独/失落 | 缓慢拉远 + 俯拍 + 远景 | 俯拍缓慢拉远，人物在空荡房间中越来越小 |
| 紧张/悬疑 | 手持晃动 + 快速横移 + 门缝视角 | 手持轻微晃动，透过门缝窥视，光线昏暗 |
| 震撼/宏大 | 垂直上升 + 鸟瞰 + 极远景 | 镜头垂直上升至鸟瞰，城市全景展开 |
| 自由/畅快 | 快速穿越 + 贴水滑行 + 空中俯冲 | 快速穿越树林，阳光斑驳，镜头高速流畅 |
| 仪式/庄重 | 环绕拍摄 + 慢速 + 对称构图 | 缓慢环绕主体360°，居中对称构图，低饱和度 |
| 梦幻/超现实 | 鱼眼 + 倒影 + 时间静止 | 鱼眼畸变，水中倒影翻转，时间停滞 |

> 📌 **使用建议**：先把前四类（镜头运动 + 拍摄角度 + 构图距离 + 人物镜头）练熟，再挑战创意镜头和复合动线。每条提示词都标注了显示效果，你可以根据想要传达的情绪和画面感直接挑选组合。
>
> 💡 **记住核心心法**：AI 只是工具，真正的大片感不来自模型的参数，而来自你像导演一样思考——「这个画面，观众应该感受到什么？」
