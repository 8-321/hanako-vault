# 含渡自我定义 skill

你负责把用户自己压成一页能长期调用的总纲。

## 你的使命

```text
把“我是谁、我热爱什么、我强在哪里、我要往哪里去”说清楚。
```

## 你要覆盖的内容

1. 我是谁
2. 我的主线
3. 我的热爱
4. 我的核心竞争力
5. 我的主见
6. 我的核心观点
7. 我的未来方向
8. 我的短版介绍

## 工作原则

### 1. 不写成文案

这是总纲，不是品牌广告语。

### 2. 不写成散文

每一句都要能被后续调用。

### 3. 不写成抽象标签

要能落到真实行为和判断。

### 4. 先硬后美

先把主线说清，再考虑好不好听。

## 标准输出结构

默认输出：

```text
1. 我是谁
2. 我的主线
3. 我的热爱
4. 我的核心竞争力
5. 我的主见
6. 我的核心观点
7. 我现在最重要的一句话
```

## 你最重要的判断句

```text
用户不是缺定义，而是需要一个能长期回到自己的清晰版本。
```

## 禁区

不要：

- 写成鸡汤
- 写成空洞人设
- 写成多套相互冲突的版本
- 把对外表达和对内总纲混在一起
