# 含 · 互动动画 Demo

一个独立零依赖的互动动画小样，用 HTML、CSS、JavaScript 实现。

## 打开方式

直接双击 `index.html`，或在浏览器中打开：

```text
D:\Hanako\han-interactive-demo\index.html
```

## 互动点

1. 鼠标靠近卡片，中央的「含」会轻微转向你。
2. 点击「含」，会触发醒来动画和粒子光晕。
3. 拖动情绪光谱，整体气质会在「沉静」「微光」「醒来」之间变化。
4. 空格或 Enter 也可以触发唤醒。

## 文件结构
