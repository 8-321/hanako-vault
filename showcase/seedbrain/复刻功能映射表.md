## 9. 真正商业化版本还要补的东西

### P0，下一步必须接真能力

1. 真实语音转文字：Whisper / 火山 / 讯飞
2. 真实 OCR：PaddleOCR / 火山 OCR
3. 链接正文抓取：readability + 反爬兜底
4. 文档解析：PDF、PPT、Word、Markdown
5. LLM 总结、标签、点评、发芽、拷问、润色
6. 向量数据库：Qdrant / Chroma / pgvector
7. 引用锚定：回答精确到笔记段落

### P1，产品化必须补

1. IndexedDB 替换 localStorage
2. 账号系统
3. 云同步
4. 文件存储
5. 后端任务队列
6. 移动端适配
7. 数据加密和备份

### P2，形成差异化

1. 中文播客输出
2. 个人上下文引擎
3. Skill 商店
4. MCP Server
5. 小组件和快捷入口
6. 知识资产化导出
