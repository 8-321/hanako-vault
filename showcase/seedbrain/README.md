# SeedBrain 复刻原型

这是一个「得到大脑类」AI 记录与创作产品的 clean-room 功能复刻原型。它复刻的是产品能力结构和用户流程，不复制官方品牌、UI 视觉、素材、文案和专有数据。

## 当前已覆盖的功能

### 记录采集

文字速记、语音记录入口、链接速记、图片记录、文档记录、会议记录、直播/博主订阅。

### 知识组织

多知识库、标签、收藏、归档、最近记录、统计、活跃主题、语义相关笔记推荐。

### AI 能力

AI 搜索、基于本地笔记的问答、点评、发芽、拷问、润色、生成朋友圈、小红书、公众号、周报、会议纪要、版本归档。

### 学习闭环

每日回顾、间隔复习占位、知识盲区提示、最近重复主题识别。

### 开放生态

CLI/API 设计页、Skill 工作流设计页、导入导出 JSON。

## 启动

```bash
cd D:/Hanako/seed-brain-replica
npm run start
```

然后打开：

```text
http://localhost:5177
```

## 重要说明

当前版本是前端本地原型，数据保存在 localStorage。AI 能力使用本地规则模拟，下一阶段可以接入真实模型、向量数据库、OCR、ASR、爬虫和后端账号系统。
