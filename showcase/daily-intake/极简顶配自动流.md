# 极简顶配自动流

你说得对：

本地网页入口虽然能用，但对日常来说还是复杂。真正应该像“微信印象笔记 / Get 笔记 / Obsidian 笔记助手”：

> 手机端只负责发送，系统自动收。

所以最终操作应该收敛成一句话：

> 看到什么，就发给 Hanako 收集助手。

## 最终体验

### 手机端

你只做一件事：

```txt
把文字、链接、语音发给 Telegram 里的 Hanako 收集助手
```

### 电脑端

电脑只要保持这个后台助手开着：

```txt
D:\Hanako\DailyIntakeLite\启动云端收集助手.bat
```

晚上生成日报：

```txt
D:\Hanako\DailyIntakeLite\生成今日信息流.bat
```

后面也可以把“生成今日信息流”做成每天自动定时。

## 已经准备好的文件

```txt
D:\Hanako\DailyIntakeLite\scripts\telegram_bot.py
D:\Hanako\DailyIntakeLite\启动云端收集助手.bat
D:\Hanako\DailyIntakeLite\config\telegram.json
```

## 分流规则

### 发链接

进入：

```txt
D:\Hanako\DailyIntakeLite\inbox\links\telegram-YYYY-MM-DD.md
```

日报会自动抓标题、description，并做链接总结。

### 发文字

进入：

```txt
D:\Hanako\DailyIntakeLite\inbox\notes\telegram-YYYY-MM-DD.md
```

### 发语音

语音文件会先保存到：

```txt
D:\Hanako\DailyIntakeLite\inbox\voice\
```

下一步可以接 Whisper 自动转文字。

## 为什么选 Telegram Bot

它比本地网页入口更接近你想要的东西：

- 手机不需要输入电脑 IP
- 分享路径更自然
- 链接、文字、语音都能发
- 以后可接自动转写
- 以后可接自动摘要
- 电脑端只是后台处理器

## 仍然需要的一次性配置

第一次需要创建 Telegram Bot，拿到 Bot Token，填进：

```txt
D:\Hanako\DailyIntakeLite\config\telegram.json
```

配置完成后，日常使用就只剩：

```txt
发给 Bot
```

这才是极简。
