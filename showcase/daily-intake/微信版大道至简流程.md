# 微信版大道至简流程

你说得对，“选中当天内容再复制”还是复杂。

我把日常动作重新压到最少。

## 手机端

只有一个动作：

```txt
看到什么 → 发给微信文件传输助手
```

## 电脑端，当前 0 元低风险版

只有两个键：

```txt
Ctrl + A
Ctrl + C
```

然后双击：

```txt
D:\Hanako\DailyIntakeLite\导入微信剪贴板并生成.bat
```

## 具体怎么做

1. 打开电脑微信
2. 点“文件传输助手”
3. 鼠标点一下聊天内容区域
4. 按：

```txt
Ctrl + A
Ctrl + C
```

5. 双击：

```txt
导入微信剪贴板并生成.bat
```

完成。

## 为什么先这样

因为这是 0 元、微信生态、低风险。

它不碰微信数据库，不读 WeChat Files，不会破坏聊天记录。

## 我接下来要做的终局版

你日常只做：

```txt
手机发给文件传输助手
```

电脑端由 Hanako 自动：

```txt
打开微信 → 进入文件传输助手 → Ctrl+A/C → 导入 → 生成日报
```

这个需要 Hanako 能控制电脑微信窗口。当前电脑控制工具在列应用时出现平台错误，我先不强冲，避免误操作。等工具状态正常，我会继续接管。

它不是终局，但已经足够简单：

```txt
手机发微信
```
