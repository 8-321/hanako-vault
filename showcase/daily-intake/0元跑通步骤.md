# 0 元跑通最小步骤

## 只做一次

### 1. 创建 Telegram Bot

在 Telegram 搜索：

```txt
@BotFather
```

发送：

```txt
/newbot
```

按提示创建，拿到 Bot Token。

### 2. 写入 Token

双击：

```txt
D:\Hanako\DailyIntakeLite\配置TelegramToken.bat
```

粘贴 Bot Token。

### 3. 启动收集助手

双击：

```txt
D:\Hanako\DailyIntakeLite\启动云端收集助手.bat
```

窗口不要关。

## 每天怎么用

手机上把这些发给你的 Bot：

```txt
链接
文字
用手机键盘麦克风说出来的文字
```

晚上双击：

```txt
D:\Hanako\DailyIntakeLite\生成今日信息流.bat
```

结果会进：

```txt
D:\BELLA KE\项目AI\调教AI\HanakoVault\00-Inbox\Daily-Intake\
```

## 0 元边界

这一版：

- 不用服务器
- 不用 Docker
- 不用数据库
- 不用 OpenAI API
- 不用 Whisper
- 不花钱

语音用手机系统“语音转文字”，发送出来就是文字。

## 测试句

给 Bot 发：

```txt
https://obsidian.md/ 测试自动收集
```

如果回复：

```txt

```

就跑通了。
