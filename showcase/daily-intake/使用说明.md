# DailyIntakeLite 使用说明

这版走大道至简：先不装 Docker，不上数据库，不自动爬微信，不做全量监控。

它只做一件事：

> 把你今天的链接和碎片笔记，生成一页干净的 Obsidian Daily Intake。

## 你每天怎么用

### 1. 丢链接

把链接放到：

`D:\Hanako\DailyIntakeLite\inbox\links\`

任意 `.txt` 或 `.md` 文件都可以，一行一个链接：

```txt
https://github.com/karakeep-app/karakeep 这个以后可能作为收藏入口
https://obsidian.md/ 最终沉淀到 Vault
```

### 2. 丢笔记

把碎片想法放到：

`D:\Hanako\DailyIntakeLite\inbox\notes\`

任意 `.txt` 或 `.md` 文件都可以。

### 3. 生成今日信息流

运行：

```bash
python D:\Hanako\DailyIntakeLite\scripts\daily_intake.py
```

会生成两份：

1. 本地预览：`D:\Hanako\DailyIntakeLite\output\YYYY-MM-DD.md`
2. Obsidian：`D:\BELLA KE\项目AI\调教AI\HanakoVault\00-Inbox\Daily-Intake\YYYY-MM-DD.md`

## 安全规则

- 脚本不会删除 inbox 原始文件。
- 脚本只读取今天修改过的文件。
- 如果当天日报已存在，只替换自动生成区域。
- `## 手动补充` 下面你写的内容会保留。
- 如果遇到旧格式文件，会先备份为 `.bak`。

## 为什么这就是第一版最优解

复杂方案看起来强，但小白每天不会用。

这一版牺牲了“全自动无死角”，换来：

- 轻
- 稳
- 美观
- 可理解
- 可回滚
- 不依赖外部平台
- 不怕封号
- 不污染 Vault

等你连续用了 7 天，再加增强：

1. 浏览器书签自动导入
2. ActivityWatch 自动读取浏览记录
3. Karakeep 一键收藏
4. RSSHub 信息源订阅
