# 只看这一页

目标：0 元跑通手机自动流。

## 你现在只需要做 3 步

### 第 1 步：拿 Bot Token

Telegram 搜索：

```txt
@BotFather
```

发送：

```txt
/newbot
```

创建一个 Bot，复制 BotFather 给你的 token。

### 第 2 步：填 Token

双击：

```txt
D:\Hanako\DailyIntakeLite\配置TelegramToken.bat
```

把 token 粘贴进去。

### 第 3 步：启动助手

双击：

```txt
D:\Hanako\DailyIntakeLite\启动云端收集助手.bat
```

然后用手机给 Bot 发：

```txt
https://obsidian.md/ 测试自动收集
```

Bot 回复“已收进今日信息流：link”就成功。

## 以后每天

手机看到什么，发给 Bot。

晚上双击：

```txt
D:\Hanako\DailyIntakeLite\生成今日信息流.bat
```

就会进 Obsidian。
