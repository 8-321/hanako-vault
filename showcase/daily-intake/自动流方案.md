# 自动流方案

你说的方向是对的：要像“微信的印象笔记”“Obsidian 笔记助手”那样，手机端一发，它自己流进知识库。

我给 DailyIntakeLite 加了一个轻量自动收集服务。

## 当前已实现

### 电脑端启动入口

双击：

```txt
D:\Hanako\DailyIntakeLite\启动手机收集入口.bat
```

它会启动一个本地网页服务：

```txt
http://127.0.0.1:8765
```

同一 Wi-Fi 下，手机访问：

```txt
http://电脑局域网IP:8765
```

然后你可以：

- 粘贴链接
- 粘贴文字
- 用手机键盘麦克风语音输入
- 提交后自动写入 inbox

## 自动分流规则

### 有链接

自动写入：

```txt
D:\Hanako\DailyIntakeLite\inbox\links\mobile-auto-YYYY-MM-DD.md
```

### 没有链接，纯文字/语音转文字

自动写入：

```txt
D:\Hanako\DailyIntakeLite\inbox\notes\mobile-auto-YYYY-MM-DD.md
```

## 语音现在怎么做

第一版不直接收录音文件，而是用手机自带语音输入：

1. 打开收集网页
2. 点输入框
3. 点键盘麦克风
4. 说话
5. 提交

这样最稳、最轻、不用装 Whisper、不上传录音、不吃电脑性能。

## 类似 Get 笔记/印象笔记的完整体验

手机端可以做成：

### 方式 A：浏览器收藏页面

把 `http://电脑局域网IP:8765` 加到手机浏览器书签或桌面。

以后想记东西，点一下就能收。

### 方式 B：iOS 快捷指令 / 安卓自动化

分享内容 → 快捷指令 POST 到：

```txt
http://电脑局域网IP:8765/api/capture
```

JSON：

```json
{"text":"分享来的内容或链接"}
```

这样就能接近“分享到笔记助手”的感觉。

### 方式 C：微信文件传输助手兜底

如果不在同一 Wi-Fi，先发文件传输助手，回电脑再一键导入。

## 重要限制

这个轻量服务只在电脑开机且服务运行时可用。

如果你想在外面、电脑关机时也能自动收，需要下一阶段上云端入口，比如：

- Telegram Bot
- Server 酱 / Bark
- 飞书机器人
- n8n webhook
- 一个极小的 VPS 接收器

我的建议：先用本地自动流验证 3 天。如果你真的高频手机记录，再上 Telegram Bot 云端入口。
