# 微信 0 元自动流

你是微信用户，所以主线改成微信。

## 最终日常动作

手机端：

```txt
看到什么 → 转发给微信文件传输助手
```

电脑端：

```txt
在文件传输助手里复制当天内容 → 双击导入微信剪贴板并生成.bat
```

这一步还没有做到完全无手，但已经不需要 Telegram、不需要国外工具、不需要服务器。

## 为什么先不直接自动读微信

我不会直接读微信数据库。

原因：

- 微信个人号没有开放 Bot API
- 聊天数据库加密
- 直接碰 WeChat Files 风险高
- 你之前丢过微信数据，这里必须保守

所以第一版只读“剪贴板”，不碰微信文件。

## 已实现

```txt
D:\Hanako\DailyIntakeLite\scripts\import_clipboard.py
D:\Hanako\DailyIntakeLite\导入微信剪贴板并生成.bat
```

## 使用方式

### 1. 手机上

把链接、文字、语音转文字发给：

```txt
微信文件传输助手
```

### 2. 电脑上

打开微信文件传输助手，选中你要导入的内容，复制。

### 3. 双击

```txt
D:\Hanako\DailyIntakeLite\导入微信剪贴板并生成.bat
```

它会自动：

1. 读取剪贴板
2. 有链接就写入 links
3. 纯文字就写入 notes
4. 生成 Daily Intake
5. 同步进 Obsidian

## 下一步真正自动化

如果你要进一步极简，我下一步会用 Hanako 的电脑控制能力做：

```txt
自动打开微信 → 进入文件传输助手 → 复制最新内容 → 导入 → 生成日报
```

这仍然不读数据库，只控制界面，安全很多。
