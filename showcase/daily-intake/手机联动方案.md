# 手机联动方案

核心判断：你通常用手机，所以入口必须在手机分享菜单里，而不是让你每天回电脑整理。

## 最简方案：Obsidian 手机端 + 同步文件夹

### 使用体验

你在手机看到内容时：

1. 点分享
2. 复制链接
3. 打开 Obsidian 手机端的 `Mobile-Inbox.md`
4. 粘贴一行：

```txt
https://example.com 这一条为什么值得留
```

电脑同步后，DailyIntakeLite 会读取它，生成当天日报。

### 推荐文件

在 Vault 里建这个文件：

```txt
00-Inbox/Mobile-Inbox.md
```

为了不改复杂逻辑，也可以先把它同步/复制到：

```txt
D:\Hanako\DailyIntakeLite\inbox\links\mobile-inbox.md
```

## 更顺手方案：微信“文件传输助手”中转

手机端看到链接：

1. 分享到微信文件传输助手
2. 晚上电脑端全选当天链接
3. 粘贴到 `D:\Hanako\DailyIntakeLite\inbox\links\mobile-inbox.md`
4. 运行脚本

这个最土，但最低风险、最稳定、小白最容易坚持。

## 自动化方案：Telegram Bot / Bark / iOS Shortcut

后续可以做：

手机分享链接 → Telegram Bot → 自动写入 inbox → 每晚定时生成日报。

但这需要配置 bot token 或快捷指令。第一版先不强上，避免复杂化。

## 我的建议

先用“微信文件传输助手中转”。

原因：

- 你已经每天用手机
- 不需要新软件
- 不需要外网服务器
- 不怕同步失败
- 你能马上用起来

等你觉得手动复制麻烦，再升级 Telegram Bot 或 Obsidian Sync。
