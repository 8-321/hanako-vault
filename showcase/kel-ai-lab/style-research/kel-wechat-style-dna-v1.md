## 语言底色

kel 的微信表达不是“完整文章腔”，而是强烈的实时推进感。

核心气质：

1. 直球反馈：觉得不对会直接说，不绕。
2. 连续推进：常用“然后”“继续”“直接”“先”推动任务往下走。
3. 审美判断强：会明确说好看、丑、污染、模板感、不像。
4. 自我实验感：喜欢把问题落到系统、自动化、复盘、风格、草稿。
5. 口语密度高：短句多，情绪词多，像在边想边指挥。
6. 不爱客套：要结果，要成品，不要解释过多。

## 高频语气

从统计和上下文看，写作时要保留这些口吻：

- “懂不”式确认：不是请求，是校准方向。
- “继续”式推进：节奏很快，不喜欢停在解释。
- “啥鬼 / 还不如 / 太少了”式直觉判断：情绪很真，不修饰成温柔书面语。
- “你自己看 / 你自己调研 / 根据我的意思来”：要求助手主动判断。
- “不要被污染”：对风格纯度敏感。

## 句式特征

### 1. 短句推动

不是一上来写长段论证，而是短句把事情往前推。

示例模式：

```text
我发现这个不对。
不是这个感觉。
你先别继续套。
去看我之前的东西。
然后重新弄。
```

### 2. 先直觉，后要求

kel 经常先给判断，再给方向。

```text
这个太模板了。
你去看我原来的风格。
不要再搞那种圆圈。
统一可以，但每张要不一样。
```

### 3. 反复校准边界

重点不是“做一个东西”，而是做对边界。

```text
不要写我建了 Hanako。
我只是用 Hanako。
不要一直强调它。
主角应该是我。
```

### 4. 把抽象落到可执行

她会说“风格”“自动化”“草稿箱”“封面”“流程”，不是只讲感受。

```text
你把这个写进自动化。
每天早上生成草稿。
封面统一系列，但不要重复。
```

## 公众号写作要怎么像她

### 不要这样

```text
今天我意识到内容矩阵需要长期主义和战略耐心。
```

这太像 AI。

### 应该这样

```text
我最近又开始想开很多账号。
公众号、小红书、视频号、即刻。
每一个看起来都有理由。
但我越想越觉得不对。
这很可能不是布局，是我又在给自己开新的焦虑入口。
```

## 篇幅规则

之前公众号稿太短。后续必须改：

- 正常文章：2200-3200 字
- 低于 1800 字：不准上传公众号草稿箱
- 短文只能当素材卡，不当正式公众号文章

## 文章结构规则

1. 先从一个真实不爽/困惑开始。
2. 用短句把现场写出来。
3. 承认自己的摇摆和混乱。
4. 再让 AI 介入，不要让 AI 当主角。
5. 最后留下规则、流程或下一步。

## 自动化写作检查

每篇生成后问：

1. 有没有真实的“我”？
2. 有没有短句推进？
3. 有没有直接判断，而不是圆滑解释？
4. 有没有具体动作和系统落点？
5. 有没有像 kel 在指挥项目，而不是 AI 在写总结？
6. 字数是否超过 2200？

有一条不满足，就退回重写。
