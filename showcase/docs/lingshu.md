# 灵枢网站产品蓝图 1.0

> 中文 AI Skill 中枢  
> 口号：灵感来了，直接导入。

## 0. 一句话定义

灵枢是一个面向普通人的中文 AI Skill 知识库。用户通过搜索或交互式问答说出想法，系统推荐可预览、可复制、可一键导入的中文 Skill；发布者只需上传、粘贴或导入材料，AI 自动整理成中文行动卡。

核心不是收录最多，而是让普通人更快找到、更快理解、更快用上。

## 1. 产品定位

### 1.1 产品名

**灵枢**

### 1.2 副标题

**中文 AI Skill 中枢**

### 1.3 首页主文案

**说出你的想法，灵枢为你找到能直接导入的中文 Skill。**

### 1.4 品牌气质

关键词：

- 极简克制
- 中文创作者基地
- 未来感操作台
- 小白友好
- 有审美筛选力
- 流动、安静、但能力很强

### 1.5 核心用户

**什么都想试的普通人。**

他们可能是学生、自媒体新手、设计爱好者、普通上班族、副业探索者、AI 工具尝鲜者。他们不一定懂 Skill、GitHub、工作流、Agent，但他们知道自己想更快做出一点东西。

## 2. 产品宪法

1. 用户不需要知道什么是 Skill，也能找到 Skill。
2. 发布者不需要会写复杂介绍，也能发布 Skill。
3. 所有 Skill 必须提供完整中文版本。
4. 所有 Skill 必须说明：适合谁、输入什么、输出什么、怎么导入。
5. 首页只服务一个动作：说出想法，找到 Skill。
6. 小白模式永远默认，高级模式永远可选。
7. 每次推荐最多 3 个主要结果，减少选择困难。
8. 界面保持极简克制，用流动交互替代复杂导航。
9. 平台不追求收录最多，只追求更快找到、更快用上。
10. 口碑来自用户第一次真的用成功。

## 3. 核心价值

### 3.1 用户侧价值

用户想要的是：

- 少花时间
- 少做选择
- 更快出结果
- 不被英文和配置吓退
- 不知道怎么问时有人引导
- 拿到的 Skill 能直接用

灵枢给用户的承诺：

> 不用懂技术，说出你想做什么，我帮你找到能直接导入的中文 Skill。

### 3.2 发布者侧价值

发布者想要的是：

- 不想填复杂表单
- 不想写长介绍
- 不想研究平台格式
- 希望自己的 Skill 被普通人看懂并使用

灵枢给发布者的承诺：

> 把你的 Skill 丢进来，我帮你整理成中文行动卡。

### 3.3 平台侧价值

长期沉淀为：

- 中文 Skill 知识库
- 普通人的 AI 工作流地图
- 中文创作者的 Skill 发布与发现入口
- 有审美、有筛选、有场景解释的 AI 能力库

## 5. 普通用户问答流

目标：解决“不知道搜什么”的问题。

入口文案：

> 不知道怎么搜也没关系，回答几个问题，我帮你匹配最适合的中文 Skill。

### 5.1 问答原则

- 最多 4 问
- 每问尽量用按钮，不要求用户打字
- 允许用户选择“我也说不清”
- 每次最终只推荐 3 个主结果
- 结果必须全中文

### 5.2 问答流程

#### 第 1 问：你现在想做什么？

选项：

- 发内容
- 做设计
- 整理资料
- 找灵感
- 提高效率
- 做副业
- 只是想试试

#### 第 2 问：你希望 AI 帮你省掉哪一步？

选项：

- 想选题
- 想写文案
- 想做图
- 想整理
- 想分析
- 想生成方案
- 我也说不清

#### 第 3 问：你想要什么结果？

选项：

- 一段可复制的文案
- 一套可执行流程
- 一个设计方向
- 一个表格
- 一个网页
- 一个自动化助手
- 一个我能马上试的东西

#### 第 4 问：你熟悉 AI 吗？

选项：

- 完全小白
- 会复制粘贴
- 会简单配置
- 想看高级模式

### 5.3 推荐结果样式

标题：

> 推荐给你的 3 个中文 Skill

每张卡片显示：

- Skill 名称
- 一句话用途
- 适合谁
- 你需要输入什么
- 它会输出什么
- 难度
- 操作按钮：导入这个 Skill、先预览、收藏

## 6. 发布者问答流

目标：解决发布者“不知道怎么写、不知道怎么整理”的问题。

入口文案：

> 把你的 Skill、prompt、GitHub 链接、zip 或 html 丢进来，剩下的我帮你整理成中文卡片。

### 6.1 发布原则

- 不强迫发布者理解平台标准
- 先丢材料，再由 AI 整理
- AI 只问必要问题
- 发布前必须生成完整中文行动卡
- 发布者只需要确认、修改或存草稿

### 6.2 第 1 步：丢材料

支持：

- 粘贴文字
- 上传 zip
- 上传 html
- 上传 SKILL.md
- 粘贴 GitHub 链接
- 粘贴 prompt

按钮文案：

> 丢进来

### 6.3 第 2 步：AI 自动识别

AI 自动识别：

- 这是不是 Skill
- 原始语言
- 是否有说明文档
- 是否有脚本或资源文件
- 是否适合普通人
- 是否存在安全风险
- 是否需要高级配置

### 6.4 第 3 步：AI 提问补全

最多问 3 个问题。

优先问题：

1. 这个 Skill 最适合谁用？
2. 用户使用前需要准备什么？
3. 你希望别人导入后完成什么结果？

如果 AI 能从材料判断，就跳过对应问题。

### 6.5 第 4 步：生成中文行动卡

AI 自动生成：

- 中文标题
- 一句话说明
- 适用人群
- 使用场景
- 输入示例
- 输出示例
- 标签
- 难度等级
- 导入说明
- 高级信息
- 风险提示
- 原始来源

### 6.6 第 5 步：发布者确认

只给三个按钮：

- 发布
- 修改
- 存草稿

## 8. 全中文规范

平台内每个 Skill 必须完整中文化。

### 8.1 必须中文化的内容

1. 中文名称
2. 中文简介
3. 中文使用说明
4. 中文输入示例
5. 中文输出示例
6. 中文标签
7. 中文风险提示
8. 中文导入说明
9. 中文适用人群
10. 中文使用场景
11. 中文错误提示
12. 中文按钮文案

### 8.2 中文化不是直译

英文原文：

> A workflow for extracting structured insights from video transcripts.

差的中文：

> 从视频转录中提取结构化洞察的工作流。

好的中文：

> 把一段视频文稿整理成选题、金句、脚本和复盘笔记。

### 8.3 中文卡片写作标准

每张卡片必须说人话：

- 不堆英文术语
- 不写空泛宣传
- 不说“提高效率”这种废话，除非说明提高哪一步
- 必须有具体场景
- 必须有输入和输出
- 必须让小白知道下一步点哪里

## 9. 高级模式

高级模式必须存在，但默认隐藏。

### 9.1 入口

右上角开关：

> 高级模式

或 Skill 卡片内按钮：

> 查看高级信息

### 9.2 高级模式内容

以右侧抽屉展示：

- 原始 SKILL.md
- 文件结构
- 依赖说明
- 适配平台
- 版本记录
- GitHub 来源
- 安全提示
- 导入日志
- 原始文件下载

### 9.3 原则

- 小白默认看不到复杂内容
- 高级用户能找到全部信息
- 技术信息不污染主界面

## 10. 流动性交互设计

灵枢的界面不做传统资源站式跳转，而做状态流动。

### 10.1 核心流

想法 → 问答 → 推荐 → 预览 → 导入

### 10.2 首页搜索流

用户输入一句话后，不硬跳转。  
搜索框下方自然浮现 3 张推荐卡片。

### 10.3 问答流

问答不做满屏客服聊天，而做轻量卡片。

每次出现一张问题卡：

> 你现在更想完成哪件事？

用户点击胶囊按钮后，下一张问题卡轻轻出现。

### 10.4 卡片展开流

用户点击 Skill 卡片后，卡片原地展开。

展开层级：

1. 一句话用途
2. 示例预览
3. 导入按钮
4. 高级信息抽屉

### 10.5 导入完成流

点击导入后显示：

> 已准备好，你可以直接使用。

按钮：

- 打开
- 复制
- 收藏

## 17. 视觉方向

### 17.1 色彩

- 米白或浅灰底色
- 柔和黑正文
- 低饱和蓝灰或青绿色作强调
- 不使用廉价霓虹渐变

### 17.2 字体与排版

- 中文可读性优先
- 大字号标题
- 大留白
- 卡片之间呼吸感强
- 避免资源站式密集布局

### 17.3 组件气质

- 搜索框像核心控制台
- 卡片像行动卡
- 标签像轻量芯片
- 高级模式像右侧控制抽屉
- 动效轻，不喧宾夺主

## 18. 成功指标

## 21. 最终判断

灵枢最强的壁垒不是 Skill 数量，而是：

- 中文化能力
- 场景解释能力
- 小白导入能力
- 审美筛选能力
- 问答式匹配能力

它应该像一个安静但强大的中文 AI 控制台。用户不用研究技术，只需要说出想法；发布者不用研究格式，只需要丢进材料；平台把混乱的 AI 技能世界整理成一张张能直接用的中文行动卡。
