# 含渡终极文件夹结构

> 这不是资料清单，是含渡的总容器。
> 原则：入口简单、分层清楚、可复用、可回滚、可长期长大。

---

## 一、总原则

```text
原始材料留本地
草稿进工作区
定稿进 Vault
执行交给 Codex
主权回到 Kel
```

含渡以后所有东西，都按这个逻辑放。

## 三、每一层放什么

### 00-入口

放你每天最先看的东西。

```text
我是谁
我现在干什么
我先看什么
```

### 01-主线

放“我到底往哪走”的判断。

```text
主线方向
未来路径
停什么
留什么
```

### 02-个人系统

放你自己怎么运转。

```text
诊断
裁决
行动
复盘
隐私
```

### 03-产品

放你要拿出去给别人用的东西。

```text
启动包
案例
反馈
说明
```

### 04-项目

放当前具体在做的事。

### 05-内容

放公众号、选题、稿件、话术。

### 06-资料

放原始材料，只读、只留证据。

### 07-模型

放长期蒸馏出来的你自己。

### 08-工具

放 Codex、脚本、skill、自动化说明。

### 09-归档

放已经结束、停掉、旧了的东西。

### 10-工作区

放临时草稿、实验、待裁决内容。

---

## 四、使用规则

```text
1. 原始材料不直接进产品层
2. 草稿先放工作区
3. 定稿才进入口或模型层
4. 能复用的进产品或模型层
5. 结束的进归档
6. 不确定的留在待裁决
```

---

## 五、你以后怎么用这个文件夹

你以后所有内容，都按这四句走：

```text
先判断它是什么
再决定它放哪
再决定它要不要进 Vault
最后决定它要不要给别人用
```

## 六、最简理解版

你只要记住：

```text
入口看自己
主线看方向
系统看方法
产品看外用
资料看证据
模型看长期沉淀
工具看执行
归档看结束
工作区看临时
```
