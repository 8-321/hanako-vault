# Hanako / Kel 总入口

大道至简：以后先看这三个地方。

## 1. 我现在在哪里

- Hanako / Obsidian 主库：`D:\Hanako`
- 聊天和项目总入口：`E:\KelWorkspace`
- Codex 聊天记录：`C:\Users\huang\Documents\Codex`

## 2. 日常怎么找东西

1. 找笔记、日记、技能：打开 `D:\Hanako`
2. 找聊天和项目：打开 `E:\KelWorkspace`
3. 找 Codex 历史：打开 `C:\Users\huang\Documents\Codex`

## 3. KelWorkspace 只看两个入口

- 聊天：`E:\KelWorkspace\01-聊天`
- 项目：`E:\KelWorkspace\02-项目`

其他英文名、旧名字、`__2`、链接目录，大多是兼容旧路径用的。平时不用管，也不要手动删。

## 4. Hanako 主库稳定位置

- 日记：`D:\Hanako\diary`
- 日记索引：`D:\Hanako\Hanako同步\日记索引.md`
- Hanako 笔记同步：`D:\Hanako\Hanako同步\笔记索引.md`

Obsidian 主库就是 `D:\Hanako`，不要再迁移到别的 HanakoVault。

## 5. 当前规则

- 先保数据，再修入口。
- 先做可见入口，再做深层整理。
- 不做大搬家，不删除生产数据。
- 旧路径能兼容就兼容，日常只暴露少数入口。

## 6. 如果又看不见

先检查 Obsidian 是否打开的是 `D:\Hanako`。
如果不是，回到这里：`D:\Hanako\总索引-点我.md`。

## 7. 自动恢复机制

Hanako 现在有一套可重放恢复机制：

- 恢复工具：`D:\Hanako\tools\hanako-recovery`
- 恢复点：`D:\OpenHanakoDev\backups\hanako-restore-points`
- 自动修复日志：`D:\OpenHanakoDev\backups\hanako-autoheal-logs`
- Windows 计划任务：`Hanako-AutoHeal`，每 30 分钟自检一次

如果 Hanako 更新后又缺文件、配置变小、Obsidian 指错库、bridge 不同步，优先跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Hanako\tools\hanako-recovery\Invoke-HanakoRepair.ps1
```

强制恢复配置层：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Hanako\tools\hanako-recovery\Invoke-HanakoRepair.ps1 -ForceConfig
```
