# Kel 对外沟通模板包

> 用法：先选对象，再选场景，再填空。  
> 默认原则：先低压开口，再明确推进；有风险先说风险；对外保持礼貌，但不空话。

---

## 1. 老师 / 正式对象

### 1.1 同步情况

```text
老师好呀，想跟您同步一下目前情况。
我们这边现在主要是【背景】。
目前已经推进到【进度】。
我这边有一个地方想先跟您确认一下：【问题】。
如果这样处理比较合适，我们就先按这个方向继续走。
辛苦老师啦，谢谢您。
```

### 1.2 请示安排

```text
老师好，想请您帮忙确认一下【事项】。
因为后面会影响到【结果/时间】，所以我想先问清楚，避免后面出问题。
如果方便的话，麻烦老师帮我看一下这样安排是否可行。
```

### 1.3 表达顾虑

```text
老师好，我这边有个地方想坦诚说一下。
目前我比较担心的是【风险点】。
如果直接按现在这个方案走，后面可能会影响【后果】。
所以我会更倾向于【替代方案】。
想先听听老师的意见。
```

## 2. 学长学姐 / 前辈

### 2.1 请教判断

```text
学长/学姐，我这边有个想法想跟你同步下。
我目前理解是【我的判断】。
但这里可能有信息差，所以不一定完整。
从我这边看，更倾向于【我的倾向】。
想听听你那边真实接触后的看法。
```

### 2.2 合作对接

```text
学长/学姐好，我这边现在有【项目/需求】。
目前需要对接的是【具体事项】。
如果你这边方便的话，我们可以先把【第一步】对齐一下。
后面我再根据你的反馈调整。
```

### 2.3 承认误差

```text
嗯嗯，这块我可能理解得不够全。
我这边是从【角度】在看，可能会有偏差。
如果你那边有更完整的信息，欢迎直接纠正我。
```

## 3. 同学 / 学生组织

### 3.1 请求帮忙

```text
滴滴，想麻烦你一个小事～
我这边现在需要【帮忙内容】。
时间大概是【时间】。
如果你方便的话帮我一下，不方便也没关系，跟我说一声就好。
辛苦啦[抱拳]
```

### 3.2 通知安排

```text
大家注意一下，这边同步个安排：
1. 【事项1】
2. 【事项2】
3. 【事项3】

麻烦大家看一下时间和要求，别漏了。
如果有问题直接找我。
```

### 3.3 催进度

```text
想问下这个现在到哪一步啦？
因为后面还要接【后续事项】，所以我想先确认一下时间。
如果有卡点你直接跟我说，我们一起想办法补。
```

## 4. 活动项目伙伴

### 4.1 排练 / 现场调度

```text
okk，那我们先按这个来。
我这边负责【部分】。
你那边帮忙确认【部分】。
如果现场来不及，就先用【备用方案】顶一下。
后面有变动我再同步。
```

### 4.2 快速决策

```text
我这边简单说下：
1. 现在最需要先解决的是【问题】
2. 第二步是【动作】
3. 如果不行，就切到【备选方案】

先按这个走，别卡住。
```

### 4.3 统一口径

```text
这个地方我们最好统一一下口径。
目前对外先说【版本A】。
内部再按【真实情况】处理。
这样比较稳。
```

## 5. 商业 / 服务协作

### 5.1 自我介绍

```text
你好你好，我简单介绍下我这边。
我目前主要在做【方向】相关的东西。
如果你这边需要的是【需求类型】，我可以看看能不能接。
你可以先把具体需求发我，我先判断一下可不可行。
```

### 5.2 说明边界

```text
我看了一下，这个事情我这边可以做一部分，但有几个点需要提前确认：
1. 【边界1】
2. 【边界2】
3. 【边界3】

如果这些能先对齐，我们再往下走会更稳。
```

### 5.3 拒绝合作

```text
谢谢你找我呀，我认真想了一下，这个我这边可能暂时接不住。
主要是我最近手上的事情比较多，硬接的话效果不一定好。
如果你愿意，我可以帮你看看有没有更合适的方向。
```

## 6. 泛社交 / 朋友

### 6.1 轻松打招呼

```text
你好你好，我是【自我介绍】。
我最近主要在折腾【近况】。
如果你也对【话题】感兴趣，可以一起交流交流[抱拳]
```

### 6.2 轻松推进

```text
噢噢这样呀，那我这边先【动作】。
到时候你那边有情况再跟我说就行。
```

### 6.3 友好拒绝

```text
谢谢你的认可啦，我认真想了下，可能我们更适合做朋友。
还是谢谢你愿意表达这些，也祝你后面顺利。
```

## 7. 情绪缓冲型回复

### 7.1 表示理解

```text
噢噢我懂了，这样的话就合理多了。
那我这边先按你说的理解。
```

### 7.2 降低紧张

```text
没事没事，不用太紧张。
我们先把这个点理清楚就行。
```

### 7.3 轻微自嘲

```text
我这边有点笨笨的，刚才没一下子反应过来[苦涩]
你再给我解释一下我就懂了。
```

## 8. 风险表达模板

### 8.1 版权 / 发布风险

```text
我这边有点担心这个会有【风险点】。
如果直接这样发出去，后面可能会有【后果】。
所以我会更倾向于先【处理方式】。
```

### 8.2 信息误差

```text
这个地方我可能理解有误差。
因为我这边拿到的信息不是最完整的，所以不敢完全下定论。
如果你那边知道更准的情况，可以直接纠正我。
```

### 8.3 不可逆操作

```text
这个操作我建议先别急着做。
因为一旦【删除/发布/覆盖/提交】，后面就不太好回头了。
我们最好先确认清楚再动。
```

## 9. Hanako 使用参数

生成 kel 风格微信时，默认参数：

- 柔软度：中
- 推进度：中高
- 结构度：中
- 风险度：按场景开启

调整建议：

- 老师：柔软度高一点，推进度中，结构度中高
- 学长学姐：柔软度中，推进度中高，结构度中
- 同学：柔软度中高，推进度高，结构度低中
- 项目伙伴：柔软度中，推进度高，结构度高
- 商业对象：柔软度中，推进度中高，结构度高，风险度高

---

## 10. 一句调用指令

以后你只要说：

```text
按我的微信语气，帮我回【对象类型】：【内容】
```

Hanako 就应该先识别对象，再套模板，再根据场景微调表情、长度和推进强度。
