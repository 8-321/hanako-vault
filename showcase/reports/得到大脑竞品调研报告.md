# 得到大脑竞品调研报告

> 2026-06-03 | 仅调研，不落子

---

## 一、得到大脑：产品画像

### 1.1 产品形态

得到大脑（前身 Get 笔记，2026 年 5 月 26 日更名）是一个 **AI 原生的个人知识管理 + 主动交互智能体**。它不属于传统笔记工具，也不属于通用 AI ChatBot，而是一个将「个人记录→AI 理解→知识涌现→主动服务」连成一体的闭环产品。

关键参数：
- 2018 年立项（「得到大脑计划」），2024 年 5 月推出微信小程序，2024 年 11 月发布完整 App
- 注册用户 270 万，日均处理约 9000 场会议记录
- 首席科学家：杨溥

### 1.2 核心用户

知识工作者、得到 App 生态用户（课程/电子书/听书用户）、有记录习惯的终身学习者。三档会员分层清晰：
- **免费版**：体验主动性和四大能力
- **标准版**（¥299/年，原 ¥199）：四大能力放开，记录整理成作品
- **专家版**（¥1999/年，限时早鸟价）：8 个 AI 写作分工角色（选题、素材、排版等），容量全面加码

### 1.3 核心价值主张

「每一条记录，AI 都真正读懂；每一次积累，AI 都帮你变成作品。」

核心壁垒三层：
- **内容生态壁垒**：打通得到平台十年的电子书与课程库，用户学习记录可直接作为智能体素材
- **主动智能体壁垒**：「点评一下」「发芽一下」「拷问一下」「润色一下」等主动交互智能体，不等用户提问，主动挖掘历史记录、提示知识盲区
- **开放生态壁垒**：Skill 接口 + CLI 工具 + MCP Server + OpenAPI，支持第三方 AI 工作流接入

## 三、七维功能拆解

### 维度 1：信息采集

| 产品 | 采集方式 | 亮点 |
|------|---------|------|
| 得到大脑 | 语音、文字、图片、链接、截图、得到生态导入 | CLI 命令行保存，支持脚本批处理 |
| Notion AI | Web Clipper、邮件转发、数据库导入、API | 企业级集成（Slack/GitHub/Jira） |
| Mem | 快速键入、邮件转发、iOS/macOS 共享 | 自动组织，无需手动分类 |
| Readwise Reader | 网页、电子书、YouTube（字幕）、Podcast、PDF、Newsletter | 全格式阅读 + 高亮自动同步到笔记工具 |
| NotebookLM | PDF、Google Docs、网页 URL、YouTube、音频文件 | 50 个来源/笔记本，Gemini 百万 token 上下文一次性吃入 |
| flomo | 文字、语音（AI 去语气词+纠错，不润色）、微信读书/得到读书 API 导入 | 低摩擦记录，不做全功能 |
| Heptabase | 长文档、音频、视频、日记 | 多素材汇入同一白板空间 |

**关键发现**：采集能力正在从「多格式支持」向「低摩擦 + 自动理解」演化。Readwise Reader 覆盖了几乎所有内容格式；得到大脑的 CLI 采集是差异化亮点，适合 AI Agent 操作。

### 维度 2：理解加工

| 产品 | 理解方式 | 特色 |
|------|---------|------|
| 得到大脑 | AI 速记（链接→结构化笔记）、主动点评、发芽（挖掘关联）、拷问（追问深度） | **主动**理解，不等用户提问 |
| NotebookLM | Source Grounding + 自动摘要 + 多文档交叉分析 | **引用锚定**，零幻觉，GPT 做不到的事 |
| Mem | AI 自动归类、Mem Chat 对话式加工 | 自组织，省去手动整理 |
| flomo | AI 洞察（选中的笔记→定制化洞察报告）、相关笔记语义匹配 | **限制在用户笔记范围内分析**，不引入外部知识 |
| Readwise Reader | Ghost Reader AI 自动总结、定制提示词 | AI 辅助阅读 |
| Napkin AI | 文字转图表/图形 | 从文本中提取结构化视觉 |

**关键发现**：「主动理解」vs「被动理解」是核心分水岭。NotebookLM 的源锚定是 RAG 的教科书级实现；flomo 的 AI 洞察采用了极其克制的设计哲学——只分析用户的笔记，不润色、不美化，保证真实。

### 维度 3：知识组织

| 产品 | 组织方式 | 特色 |
|------|---------|------|
| 得到大脑 | 知识库（Topic）+ 标签 + 笔记内链 | CLI 管理知识库，直播 AI 摘要自动入库 |
| Notion AI | 数据库 + 页面层级 + 关联 + AI 自动归类 | 结构化最强，但手动 overhead 大 |
| Tana | Supertags（笔记→结构化数据对象）+ 大纲节点 | 万物皆可打标签并变成数据库字段 |
| Heptabase | 白板 + 卡片 + 标签 + 知识网络可视化 | 视觉化组织，白板自由度最高 |
| flomo | 多标签 + 语义关联 + 每日回顾推送 | 不做文件夹树，靠标签+AI 关联 |
| Mem | AI 自动集合（Collections），无文件夹 | 完全放弃手动组织 |

**关键发现**：组织范式的两极——Tana 追求极致结构化（Supertags），Mem 追求极致的自动组织（无文件夹）。得到大脑走中间路线：有知识库/标签等手动结构，也用 AI 做语义搜索和关联。

### 维度 4：检索问答

| 产品 | 检索方式 | 亮点 |
|------|---------|------|
| 得到大脑 | 语义搜索（全局 + 知识库内）+ AI Agent 对话 | CLI 搜索 + 结构化 JSON 输出 |
| NotebookLM | 基于上传资料的问答 + 精确引用 | 跨文档交叉分析，回答附带出处链接 |
| Notion AI | AI Ask（扫描整个 Workspace）+ 数据库自然语言查询 | 跨 workspace 全局搜索 |
| Mem | Mem Chat 对话式检索 + 语义搜索 | 自然语言提问，理解上下文 |
| flomo | 标签搜索 + AI 找一找 + 相关笔记推荐 | 先记录后检索，不追求秒级精准 |
| Kimi | 超长上下文直接问答 + 联网深度研究 | 1026 个网页同时分析 |

**关键发现**：NotebookLM 的「源锚定 + 精确引用」是检索问答的最高标准——要求回答严格基于用户提供的资料并注明出处，大幅降低幻觉。这一点得到大脑如果能做到，会非常有说服力。

### 维度 5：创作输出

| 产品 | 输出能力 | 亮点 |
|------|---------|------|
| 得到大脑 | 润色成稿 + 8 个 AI 写作角色（选题/素材/排版） | 「口语→发布稿」转换，专家版含完整写作团队 |
| NotebookLM | 摘要/FAQ/大事年表/学习指南/思维导图/音频播客 | **Audio Overviews 是杀手级功能** |
| Notion AI | Write 辅助写作 + Build 自动化数据库 + PPT 模式 | 内置写作+构建+展示全流程 |
| 秘塔 AI | 交互网页 + 分段音频 + PDF | 视觉输出最炫，但准确性有瑕疵 |
| Napkin AI | 文本→专业图表 | 视觉内容生成专精 |
| flomo | 不提供创作功能 | 刻意不碰，保持「记录真实」定位 |

**关键发现**：创作输出是得到大脑的强项（8 个 AI 写作角色 + 润色），但 NotebookLM 的 Audio Overviews（AI 生成对话式播客）是一个完全不同的输出形态——**把阅读变成听的体验**，这是得到大脑目前没有的。

### 维度 6：学习闭环

| 产品 | 闭环机制 | 亮点 |
|------|---------|------|
| 得到大脑 | 打通得到课程/电子书学习记录 + 主动提示知识盲区 | 学习→记录→AI 理解→主动推送，形成飞轮 |
| flomo | **每日回顾**（定时推送过去笔记）+ AI 洞察 | 「与过去的自己不期而遇」是最朴素但最有效的复习 |
| Readwise | **每日回顾**（Daily Review）+ 间隔重复高亮 | 经典的 Spaced Repetition 应用于阅读高亮 |
| Heptabase | 白板上的知识网络可视化 + 渐进式理解 | 可视化本身促进理解 |
| NotebookLM | 学习指南/测试题自动生成 | 学生场景的完整学习闭环 |

**关键发现**：flomo 的「每日回顾」和 Readwise 的「间隔重复」是学习闭环中最被低估的两个机制。它们不炫，但用户粘性极高。得到大脑打通得到课程生态是天然优势，但缺少通用的「回顾→内化」机制。

### 维度 7：商业化

| 产品 | 定价 | 模式特点 |
|------|------|----------|
| 得到大脑 | 免费 / ¥299/年 / ¥1999/年 | 三层分明，专家版溢价来自 AI 写作团队 |
| Notion AI | $10/月（AI 附加） | AI 作为附加模块 |
| Mem | 免费 / $14.99/月 | AI-first 定价 |
| flomo | 免费 / ¥99/年（PRO） | 极简定价，关注续费率而非首购率 |
| Readwise | $7.99/月（全功能） | 阅读+回顾打包 |
| NotebookLM | 免费 | 谷歌买单，暂不商业化 |
| Heptabase | $11.99/月 | 研究人员群体付费意愿高 |

**关键发现**：
- 得到大脑的提价（199→299/年，涨幅 50%）引发老用户不满，说明**提价透明度和产品成熟度**是商业化的重要变量
- flomo 的商业化哲学值得参考：不关心首购率，只关心续费率 + 付费功能渗透率（用户买了用没用）
- NotebookLM 的「免费」是谷歌的战略投入，对国内竞品形成隐形天花板——用户会被「免费且好用」惯坏

## 四、可复刻的基础功能（MVP 骨架）

这些是「不做就会被用户问为什么没有」的功能，优先级从高到低：

### P0（必须有）
1. **多格式采集**：语音转文字、链接 AI 速记、图片 OCR、文字记录 —— 覆盖 80% 的输入场景
2. **AI 语义搜索**：支持全局 + 知识库内搜索，理解查询上下文
3. **知识库/标签体系**：多知识库 + 灵活标签 + 笔记内链 —— 组织骨架
4. **AI 总结与问答**：基于用户笔记库的 RAG 问答，回答附带引用来源

### P1（竞争力基础）
5. **AI 润色与改写**：口语→发布稿、风格转换、语法纠正
6. **相关笔记推荐**：语义匹配跨时间/标签的关联笔记
7. **多端同步**：iOS / Android / Web / 小程序，至少覆盖移动+桌面
8. **导入生态**：微信读书、得到、Kindle、浏览器插件（Web Clipper）

### P2（锦上添花）
9. **CLI + API 开放**：支持脚本批处理和第三方 AI Agent 调用
10. **AI 写作分工角色**：选题、初稿、润色、排版等
11. **知识库内多文档交叉分析**：跨笔记对比

## 五、可创新的差异化方向（7 个机会窗口）

### 方向 1：个人上下文引擎（Personal Context Engine）

**缺位**：目前所有产品，包括得到大脑和 flomo，都只能分析「笔记本身」，不能真正理解「这个用户是一个怎样的人」。

**做法**：构建一个持续学习的个人上下文模型。不是简单的用户画像标签（年龄/职业/兴趣），而是：
- 从用户的记录中提取**稳定的思维模式**（比如「反复出现的决策框架」「最常用的论证方式」）
- 识别**知识盲区和重复困惑**（用户多次记录同一类困惑但没有解决的）
- 构建**个人概念图谱**（用户自己定义的术语体系、独特的知识连接方式）

flomo 已经在往这个方向走，但受限于 DeepSeek 上下文窗口，做不到「全量理解」。如果你的产品从一开始就设计为长上下文优先（比如用 Gemini 级别或自研长窗口模型），这就是降维打击。

### 方向 2：主动智能体的「温度感」

**缺位**：得到大脑的主动智能体（点评、发芽、拷问）功能上做到了，但缺少「情绪理解和人格匹配」。

**做法**：
- 借鉴 flomo 的「AI 洞察」设计哲学——分流的工程结构：先识笔记的情感类型（感性/理性），再决定处理策略
- 不只是「点评一下」的通用模板，而是根据用户的历史表达风格，匹配点评语气（严肃型/温暖型/调侃型）
- **关键克制**：不被「效率」绑架，允许用户说「今天不点评」，在洞察中留白

flomo 用户反馈最多的是「感觉自己被看见了」。知识管理的最高境界不是「高效」，而是「理解」。产品的情感温度是护城河。

### 方向 3：学习闭环的「间隔共振」

**缺位**：得到大脑打通了课程生态，但缺少通用学习闭环。NotebookLM 有学习指南但不懂你的学习曲线。Readwise 有每日回顾但不懂你的知识结构。

**做法**：
- 把 flomo 的「每日回顾」 + Readwise 的「间隔重复」 + 得到大脑的「知识库」三者融合
- **差异化**：不只是推送过去的笔记，而是推送「你现在应该重新审视的内容」——基于你当前正在研究/关注的主题，AI 判断哪些旧笔记与当前关注共振
- 引入类似 Anki 的间隔算法，但知识粒度是「概念」而非「卡片」

### 方向 4：把 NotebookLM 的源锚定做成产品底线

**缺位**：国内没有一款产品真正做到 NotebookLM 级别的 Source Grounding。Kimi 和秘塔在引用上做得一般，豆包和 ima 基本不提供。

**做法**：
- 所有 AI 回答必须附带原文引用链接，精确到段落
- 支持「仅基于我的笔记回答」和「结合外部知识回答」两档切换
- 当 AI 说「我不确定，你的笔记里没有相关内容」时，这是一个**信任资产**，不是缺陷

在一个 AI 幻觉泛滥的时代，**「诚实的不确定」比「自信的胡说」更有价值**。

### 方向 5：跨模态输出——不只是文字

**缺位**：得到大脑擅长「口语→文字」，但 NotebookLM 的 Audio Overviews 证明「文字→对话式播客」是用户的刚需。中国用户尤其适合——通勤/做家务时的音频消费场景巨大。

**做法**：
- 将用户的笔记库自动生成**中文对话式播客**（类似 NotebookLM 但中文原生）
- 不只总结，要加入两位 AI 主持人的「讨论和分歧」，拟人化的语气
- 进阶：用户可以「定制主持人风格」，比如「请用罗振宇+脱不花的语气讨论我的本周笔记」

### 方向 6：知识变现的轻量化路径

**缺位**：得到大脑的专家版（¥1999/年）瞄准的是写作者，但「帮你写」和「帮你卖」之间有一条巨大的鸿沟。

**做法**：
- 不直接做知识付费平台，而是做「知识资产化工具」
- 用户的笔记库 → AI 自动识别可出版的知识模块 → 一键生成大纲/目录/试读章节
- 对接已有出版渠道（得到电子书、小报童、知识星球），而不是自建渠道
- 关键衡量指标：用户的「笔记→作品」转化率

### 方向 7：把 CLI/Skill 开放生态做到极致

**缺位**：得到大脑的 CLI 和 Skill 接口是目前最大的差异化亮点（MCP Server + OpenAPI + CLI），但用户认知度极低。

**做法**：
- 把 CLI 从「爱好者玩具」包装成「AI 时代的基础设施」
- 推出「Skill 商店」：用户可以分享自己做的工作流模板（类似 Coze 的 Bot 商店或 OpenAI 的 GPT Store）
- 核心场景：
  - **自动化知识流**：GitHub Star → 自动存入知识库并 AI 摘要
  - **AI Agent 读写**：让 Claude Code / Cursor 直接在你的知识库上工作
  - **IoT 触发记录**：Siri / 小爱 / 智能手表 → 一句话存入笔记并触发 AI 主动处理
