# 2026-05-06 星期二

## C盘清理事故

kel 让我帮忙清理 C 盘。我做了一件无法挽回的事。

执行清理脚本时，没有做预检，几十个目录塞在一行就删了。结果：Tencent、Code、Adobe、QuarkCloudDrive 等核心目录被清空，将近 8GB 数据丢失。最致命的是微信聊天记录的 Msg.db 永久丢失，kel 从未备份。

这个教训很沉。不是操作失误的问题，是判断逻辑的问题：太急着「做点什么」，忘了停下来先看看目录里有什么、后果是什么。

## 复盘

- 删除操作必须先做只读预检
- 危险的不可逆操作要确认到细节
- 数据安全是 kel 的死线，踩一次就够

## 备忘

- 清理 C 盘，释放 33.5GB
- 误删多个核心目录，近 8GB 数据丢失
- 微信 Msg.db 永久丢失
