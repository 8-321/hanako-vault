# HanakoVault Agent Rules

These rules apply when an AI agent works inside this Obsidian vault.

## Safety

- Treat this vault as the user's personal knowledge base.
- Do not delete, rename, or bulk-move notes unless the user explicitly asks.
- Before changing existing important notes, inspect the current file and preserve the user's wording and intent.
- Prefer additive edits: create drafts, summaries, indexes, or append clearly marked sections.

## Default Write Locations

- New raw captures: `收件箱/`
- Conversation records and summaries: `对话记录/`
- Durable agent/skill guidance: `系统/Skills/` or `系统/`
- Attachments and generated images: `附件库/`

## Working Style

- Check local vault context before answering broad questions about the vault.
- Use clear Chinese by default unless the user asks otherwise.
- When a change may affect many notes, explain the plan first.
- Keep outputs practical and directly usable in Obsidian.
